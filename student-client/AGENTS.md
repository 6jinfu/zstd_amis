# 学员端独立项目工作准则

先读 README.md、QA.md；Web 端参考 学员端功能说明.md，移动端参考 mobile/README.md 与 mobile/FUNCTIONS.md。

- 本项目只包含学员端。保持独立、无依赖静态应用，除非用户明确要求技术栈迁移。
- Web 端修改 student.html，图片在 assets/；移动端优先修改 mobile/app.js、local.css、detail-canvas.css。
- mobile/source/ 是原站编译文件，应保留来源完整性；没有可直接重建的 Vue SFC 源码。
- Web 与移动端数据不同，不要自动混用或改写原始快照。
- 不向真实 21TB 平台提交、删除或保存业务数据。本地演示操作不得写入原站。
- 保持相对路径，不依赖原项目绝对路径。移动端 local.css 引用 ../assets/，不要遗漏共享图片。
- 最小必要修改，不顺手重构、格式化无关文件或新增未要求的功能。
- 禁止使用任何一边带装饰色条或彩色描边的卡片。已有遗留样式不构成允许新增的依据。
- 禁止装饰性小字标签、英文副标、注释式氛围文案；无真实信息价值的副标直接删除。
- 代码修改需做相关语法检查；UI 修改需用浏览器验证。移动端至少检查 390px 与宽屏预览，以及目标页签和详情返回。
- 若涉及持久化，验证刷新后正确保留；测试数据须清理。更新 QA.md，明确未验证项。
