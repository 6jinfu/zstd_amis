# 景旺电子人才发展演示模板

日期：2026-09-28  
规格：16:9；guizang 瑞士国际主义风；克莱因蓝单一强调色；HTML 横向翻页与可编辑 PPTX 同步。  
用途：由讲者填写正式内容。所有方括号文字都是占位符，不代表客户事实、产品承诺或实际案例。

主题节奏：accent → light → dark → grey → light → grey → dark → light → light → grey → light → dark → light → grey → light → split。所有正文页使用 guizang 登记版式；顶部标题左对齐。

这是可选页型库，不要求正式演示连续讲完 16 页。若后面还有 10–15 分钟的平台操作演示，可从前 8 页选取设计思路页，再按资料成熟度选用案例页和规划页。HTML 为单文件，可离线打开；PPTX 的文字、线条和卡片可直接编辑。

## 使用提醒

- 图片槽位已按目标比例标记。案例主图建议至少 1600px 宽、21:9；证据截图建议保留原字和数据，放入 16:10 的白底框内，不放大裁切。
- 规划页的阶段和能力都是待填写模板；请在正式内容中区分已确认目标、实施依赖与时间承诺。
- 案例页的数据、截图和客户名称需要有真实来源，避免把示意值当成交付成果。
- 网页稿保留 guizang 的翻页、演讲者模式、备注和低功耗模式；PPTX 文字和图形可编辑。两种格式的页面顺序与布局对应。
