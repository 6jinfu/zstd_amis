# 人才发展片头 · V3

规格：1728 × 1117，8 秒，60 fps，无音轨。

文案：人才发展 / 让人才成长，支撑业务发展。

## 本版调整

- 以持续变形的开放丝带代替固定的闭合环，加入卷曲、舒展、扭转与波浪传播。
- 丝带沿弧线从左下进入，随后展开，为标题腾出清晰的阅读区域。
- 标题逐字揭示并轻微回弹；透明度独立渐入，避免回弹引起亮度闪烁。
- 主文案分两段落定；阅读阶段以缓慢的背景波动、灯光变化及轻微呼吸运动维持画面活力。
- 末尾丝带向右上离开，画面过渡至白色，方便连接产品界面。

## 文件

- `talent-intro-v3.mp4`：轻量传输版，H.264 4:4:4。
- `talent-intro-v3-edit.mov`：ProRes 4444 剪辑版，建议优先用于剪映。
- `talent-intro-v3-preview.webm`：浏览器预览版。
- `index.html`：可编辑 HTML，直接在本机浏览器打开即可播放，需保留 assets 文件夹。
- `poster.png`：成片第 5 秒预览。
- `verification.json`：视频规格与完整解码帧数验证结果。

字体使用本机苹方，Three.js 与 GSAP 为本地资源，无需联网加载。HTML 支持 `?t=秒数` 定位关键帧；减弱动态效果的系统设置下显示第 5.5 秒静态画面。

## 验证

已检查丝带入场、卷曲、标题回弹、舒展、阅读及收尾关键帧，脚本语法检查通过。HTML lint 无错误，仅保留单场景嵌套结构的 Studio 编辑提示，不影响渲染。

视频导出后核对尺寸、时长、帧率与完整解码帧数，结果保存在 verification.json。尚未在剪映中实际导入验证。

1117 为奇数高度，MP4 使用 4:4:4 编码以保留精确尺寸；播放器不支持时可使用 MOV 或 WebM。
