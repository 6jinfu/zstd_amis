# Screen Studio：功能录屏补录清单

先完成粗剪，再按不满足的成片位置补录。每段录屏要包含一次必要操作和操作后结果，不只录停在页面上的全景；每段前后另留2秒。无需先录完全部清单。

| 成片位置 | 补录功能 | 应录动作与结果 |
| --- | --- | --- |
| 00:08–00:13 | 4D入口 | 聚焦人才发展入口，进入模块；不展开其他模块 |
| 00:13–00:47 | 组织结构 | 矩阵全景；点击岗位族，展开岗位清单；打开一个岗位的归类依据 |
| 00:47–01:10 | 关键岗位 | 结果全景；切换实际已有的分析视角；选岗位查看建议与判断依据 |
| 01:10–01:50 | 人才标准 | 打开岗位标准；切换职责、经历、能力、动力、潜力；完整展示一项职责和能力；打开指标选择并返回标准 |
| 01:50–02:30 | 360评估 | 已有项目完成情况；评价关系；选择已完成人员，打开个人报告；综合结果和具体能力 |
| 02:30–03:20 | 人才盘点 | 宫格全景；点击宫格查看人员和能力绩效结果；同一人员初始落位、调整后位置、校准记录；回到项目结果 |
| 03:20–03:53 | 岗位地图 | 按序列查看职级岗位矩阵；选当前岗位，查看发展通道和目标岗位 |
| 03:53–04:26 | 学习方案 | 目标岗位标准与能力；岗位方案采用标准和资源；课程、项目选择与关联；保存后的资源配置 |
| 04:26–04:50 | 个人档案 | 从人才列表进入人员档案；岗位要求与实际能力对照；最近一次已结束盘点结果 |

操作出现前保持页面位置可识别，点击或展开后先等待结果稳定，再停留供阅读。组织依据、能力要求、校准记录和方案资源等复杂结果，一般留5–10秒。具体切点按完整结果和字幕阅读时间确定，不以鼠标运动速度凑时长。

录屏保持同一窗口比例、缩放和导航状态，关闭通知。默认保留窗口全景，需要读详情时做一次平缓聚焦。保留干净原始录屏，方便剪映重新裁切；不要连续自动放大鼠标。

优先沿用相关岗位和同一人员。没有连续案例时按模块展示，不通过改名字、数字或拼接画面制造数据联动。标准到资源没有直接点击入口时分别录制，再用分镜衔接。

补录只替换画面轨，声音只用无人声BGM；屏幕字幕随功能操作和结果显示。文件按成片位置命名，例如 `00-27_岗位族展开.mov`、`02-54_初始落位.mov`、`03-53_目标岗位标准.mov`。
