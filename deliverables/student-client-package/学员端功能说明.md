# 人才发展学员端功能说明

## 1. 页面定位

本交付包只还原“人才发展学员端”，不包含管理端左侧菜单、管理端顶部应用标签，也不把课程中心、资料中心、直播中心等独立平台应用混入本页面。

入口文件为 `student.html`。页面采用本地静态数据和本地资源，打开后默认进入“我的发展 / 人才画像”。

## 2. 页面层级

### 2.1 顶部模块

- 人才发展学员端标题。
- “我的发展”和“团队发展”模块切换。
- 当前学员信息：刘金富（3604）、性别、年龄、部门、岗位、职级。
- 最近在学：薪酬福利管理制度设计。

## 10. 数据与边界

- 本包是静态还原，不连接真实接口，不提交真实业务数据。
- 页面中的人员、课程、项目、统计数字是本次原网页采集到的演示数据。
- 课程播放、考试提交、问卷填写、资料上传、直播进入和后端保存不属于本次交付功能。
- 所有页面图片已经复制到 `assets/` 并改为相对路径；交付包内不存在必须访问原站才能显示的图片引用。
