# 人才发展学员端还原交付包

这是“人才发展学员端”的独立静态交付包，只包含学员端页面、页面运行所需图片资源和功能说明，不包含管理端页面。

## 启动方式

1. 在本目录打开终端。
2. 执行：

   ```bash
   python3 -m http.server 4180 --bind 127.0.0.1
   ```

3. 浏览器访问：<http://127.0.0.1:4180/student.html>

也可以直接双击 `student.html` 打开；使用本地服务器时，岗位地图图片、课程封面和其他本地资源加载更稳定。

## 交付内容

- `student.html`：学员端完整单文件页面，内含 HTML、CSS、JavaScript、路由、页面数据和交互逻辑。
- `assets/`：岗位地图路径/人物、学习方案课程封面、用户头像、指标图标、空态图和资源推荐图。
- `学员端功能说明.md`：页面层级、功能范围、交互、数据和验收说明。
- `交付清单.sha256`：交付文件校验清单。

## 说明

- 页面按照原网页实际渲染结构、字段、页面层级和图片资源复原，学习方案不再使用空白占位。
- 本包已经将 `student.html` 中的图片引用全部改为包内相对路径，页面不依赖原站图片地址即可显示。
- 页面是本地静态演示版本，数据和操作不会写入真实 21TB 系统；课程进入、考试提交、资料上传等后端业务不在本次交付范围内。
