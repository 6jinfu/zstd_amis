## 2026-11-12 人才中心实施补充

人才库导入已在本地原型实现，统一改为线上人员配置的七字段：工号、姓名、能力类别、能力名称、能力等级、能力得分、来源。得分选填，其他必填；等级1–10，得分0–999、最多两位小数；类别按完整路径匹配词典。下载模板、上传校验、预览及确认追加共用档案记录，最新有效等级替代最高值，保留历史。模板带填写参考，.xlsx/5MB/2000条；原型本地持久化已实现，后端、权限及动态词典尚未接入。本条替代下文人才中心的旧模板和“尚未实现”描述；人才图谱仍保留旧逐项模板，宫格使用人员总分模板，三处不可混为同一已接通流程。具体以当前PRD §9.1.1为准。

## 设计范围

2026-11-12 宫格盘点最新调整：绩效模板为工号、姓名、绩效等级、绩效得分；能力测评结果模板为工号、姓名、能力得分（每人一条总分）。分数0–999、最多两位小数，0有效；原始绩效等级不限定低中高，两轴均按得分排名自定义2–5档。模板含6行说明、第7行表头、第8行示例，第9行起填写；页面下载预填当前盘点人员。宫格总分不自动写入逐项能力档案；下文逐项能力模板继续用于人才中心/人才图谱。

覆盖人才标准、能力指标、人才盘点能力数据、发展序列、人才中心能力数据。人才标准两个视图共用一套模板；人才盘点和人才中心能力数据共用同一结构。沿用现有页面、按钮、弹窗和表格样式。

人才标准应用范围仅为**指定岗位**和**暂不关联**。现有代码及旧 PRD 中仍存在条件匹配，这与最新结论不一致；本设计不提供条件组或条件匹配导入。原型和历史数据的迁移需另行处理，不得把旧条件静默转为岗位或删除。

导出默认使用当前筛选范围；有选择列且已勾选时导出选中项，按钮旁明确显示数量，避免误解。标准导出保留完整关联，不因岗位筛选而截断共享标准。超过权限范围的数据不导出，并提示受限；导出范围不完整时不提供可回导更新文件，避免误覆盖。

## 二、统一导入交互

使用与现有管理端一致的弹窗：

```text
导入人才标准                                      ×

1. 下载模板并填写
   请按模板中的说明填写，带 * 的字段为必填项。
   [下载模板]

2. 上传填写完成的文件
   [选择文件]  支持 .xlsx

   有同标识的数据： (•) 仅新增  ( ) 更新已有数据

                                      [取消] [开始校验]
```

1. 模板为 Excel `.xlsx`，说明、字段和示例在各数据工作表内，星号表示必填；示例行不计入导入。人才标准按业务结构拆为六张表，其余模板暂保留单表方案；各表注明填写起始行。模板表头和工作表名不得修改。
2. 上传后先校验格式、必填项、重复项、引用关系、权限及业务约束；校验阶段不写入。
3. 校验结果显示文件名、新增数、更新数、错误数，以及涉及的人员或业务对象数。错误列出工作表、行号、字段和原因；支持下载原内容加错误说明的文件，修改后重新上传。
4. 存在错误则禁止确认；校验通过后展示新增、更新及关联变化，用户点击“确认导入”才整批写入。更新时服务端重新检查冲突，失败整批回滚。
5. 导入成功显示结果数量，列表刷新；失败明确原因，文件与现有数据不变。重复提交要避免生成重复记录。

对于标准、指标和序列，默认“仅新增”；选择“更新已有数据”时，以导出文件中的稳定标识定位对象，预览更新内容。空白单元格和缺失行默认不删除原数据；关联删除或字段清空通过系统现有编辑功能完成。新建文件内的临时标识只用于表内关联，不能凭名称覆盖已有记录。

能力数据采用追加记录而非覆盖模式，不展示“更新已有数据”选项。同一文件内相同人员、能力、测评日期的重复记录提示错误；历史记录的重复处理应在校验结果展示，避免重复导入。

## 三、人才标准模板和导出

不再采用“内容类型”、文件内标准编号或职责编号。一个 Excel 包含六张表，每张表的第 7–9 行为示例，从第 10 行起填写。各表以标准名称和标准类别关联；如果系统中不能唯一匹配，提示用户处理，不按名称猜测更新。此匹配方式不能安全表达标准改名，改名应在系统内操作；回导更新时的稳定身份识别仍需另行设计。

| 工作表 | 字段 | 结构 |
| --- | --- | --- |
| 基本信息和岗位 | 标准名称、标准类别、标准说明、应用方式、岗位编号、岗位名称 | 一个岗位一行；无关联岗位的标准一行，岗位列留空 |
| 职责任务 | 标准名称、标准类别、职责、任务 | 一个任务一行；同一职责的多条任务重复填写职责；无任务可留空 |
| 经历经验 | 标准名称、标准类别、经历经验 | 一条经历一行 |
| 能力要求 | 标准名称、标准类别、能力名称、要求等级 | 一项能力一行，等级为 L1–L10 |
| 动力要求 | 标准名称、标准类别、动力名称 | 一项动力一行 |
| 潜力要求 | 标准名称、标准类别、潜力名称 | 一项潜力一行 |

标准名称、类别和内容须遵守现有编辑器约束；现有能力数量上限在导入时同样校验。岗位通过岗位编号匹配，指标名称必须唯一精确匹配，不自动新建岗位或指标。导入入口仅设置在两个列表视角，不在岗位详情设置入口。指定岗位切换为暂不关联属于显式应用方式变化，更新预览须列明关联移除并确认；其他缺失行不删除关联。

导出目标为复用同一工作簿结构，包含标准所有内容和关联岗位；能否安全用于回导更新取决于稳定身份方案，尚未确定。学习方案不在人才标准模板内，导入标准不创建、修改或删除学习方案。

## 四、能力指标模板

2026-11-16 最新：模板已按当前编辑器修订为能力名称、类别路径、维度、能力定义、等级、分级描述、行为表现；不使用能力编号及等级名称。名称、类别、维度必填；完整类别路径和名称共同识别，同一能力多等级逐行填写，等级1–10，定义及两项等级描述各最多1000字。第8行为示例，第9行起填写。入口与模板下载已在原型中提供，上传校验、写入和导出未实现；身份与更新策略待评审。本段取代下方旧字段说明。

单工作表字段：能力编号、能力名称、类别路径、能力描述、等级、等级名称、行为描述。每行一个能力等级；同一能力多个等级时重复能力基本信息。不分级的能力填写一行，等级与行为描述留空。

能力允许不分级；分级时同一能力的等级不可重复。类别路径使用完整层级；重名能力或类别歧义需明确报错。导出按同一结构包含能力定义与全部已有等级。指标更新不能因未填写的等级行而删除原等级，也不静默修改引用该指标的标准要求或历史评测。

## 五、能力数据模板：人才中心与盘点共用

单工作表中包含说明、示例和填写区。能力数据一行表示一名人员的一项能力结果：

| 字段 | 填写规则 |
| --- | --- |
| *工号 | 文本，匹配系统已有人员，保留前导零 |
| 姓名 | 辅助核对，不修改人员基础资料；模板不包含部门、岗位 |
| *能力标识 | 匹配已有能力指标；能力名称仅作核对 |
| 能力得分 | 数值，可为空；分值范围及其来源须明确 |
| 能力等级 | L1–L10，可为空；必须属于该能力已定义等级（若该能力维护了等级） |
| *测评日期 | YYYY-MM-DD，用于判断新旧 |
| 来源说明 | 填写外部来源或测评方式，系统另外保留导入来源及导入时间 |

得分和等级至少填写一项；不存在的人员、指标、无效日期、重复行、超出范围或与分值口径不符均报错。缺失不是 0；不根据等级推算分数。测评日期相同的记录按生成或导入时间排序；记录生成时间相同时以稳定记录标识打破并列。人才档案按人员＋能力使用最新有效记录，保留历史和来源；人才中心及盘点导入均自动进入统一能力记录，无“同步人才档案”选项。

**人才中心下载**为空白数据模板。**盘点下载**在已选盘点人员后生成同结构模板，自动带入工号、姓名；按本次已选能力生成“人员 × 能力”行。还未选人员或能力时给出明确提示，不生成空白冒充已带入人员。上传只接受本次盘点人员，并展示匹配人数、覆盖人数、缺失及错误；人员或能力选择变更后应重新下载及校验。

盘点既可选择系统测评项目，也可导入结果，并可同时使用。360/考试与线下导入在进入盘点计算前归一为人员、能力指标、得分、等级、测评日期及来源信息的同一记录结构；项目编号和导入文件为来源引用。同一人员同一能力存在多个来源时，默认采用最新有效结果，并显示来源和测评日期。创建盘点时保存采用结果的快照，后续最新结果变化不重算已创建盘点。仅有等级的结果可展示或比较等级，但不能进入需要数值得分的宫格排序和定量图谱。不同评分量纲不直接合并；计算口径未配置时提示，不能虚构换算或综合分。

## 六、发展序列模板

单工作表字段：序列编号、序列名称、职级编号、职级编码、职级名称、等级序、通道编号、通道名称、通道排序、岗位编号和岗位名称。一行表示一个通道及职级下的岗位节点；同一序列、职级和通道可在多行重复，空节点的岗位字段留空。

序列、职级、通道按稳定标识关联；文件内的新建对象使用临时标识。未匹配到岗位或职级、重复节点、超出现有地图约束时停止导入。新增和更新预览分别显示对象及挂载变化；不因缺失行删除节点或学习方案。实际落地时须先统一岗位地图与系统设置的数据来源，再接入导入，不能只更新其中一个本地副本而声称同步。

## 七、状态与验收

- 各入口按钮位置与现有页面布局一致；键盘可完成下载、上传、校验、确认和关闭。
- 四类模板均包含填写说明、字段与示例；标准两个入口和能力数据两个入口分别使用相同结构。
- 盘点模板仅预填真实已选人员，工号匹配；变更人员后不能沿用旧文件悄然通过。
- L1–L10 在能力定义、标准要求、人员能力数据一致；不得自动换算得分。
- 人才档案展示最新有效能力结果；盘点创建后使用快照；历史结果可追溯。
- 校验错误不产生任何写入；重复导入、权限不足、文件过期、并发变更有明确反馈。
- 具备导入和导出权限检查、操作日志，以及人员能力数据的访问控制；日志不记录不必要的敏感内容。
- 这是待实现设计：当前静态原型的上传、下载和部分绩效展示只是演示，不能宣称已完成真实文件处理、后端事务或人员数据同步。
