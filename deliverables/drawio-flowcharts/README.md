# Draw.io 流程图交付

这些文件可直接在 diagrams.net / draw.io 中通过“文件 → 导入”打开。

全部页面已经按业务阶段重新排列：主流程采用蛇形分段布局，分支保留独立行，
节点间距和画布尺寸会随内容自动扩展，连线统一使用正交路由。打开后不需要再执行
draw.io 的“自动布局”，以免判断分支被重新打散。

- `00-overall.drawio`：整体业务流程
- `01-standard.drawio`：标准中心
- `02-assessment.drawio`：测评流程
- `03-review.drawio`：人才盘点流程
- `04-development.drawio`：发展中心
- `05-talent.drawio`：人才中心
- `06-settings.drawio`：系统设置
- `人才发展系统-全部流程图.drawio`：以上 7 张图的多页面汇总文件

## 图例

- 蓝色：当前业务处理
- 绿色：业务输出或已发布数据
- 黄色菱形：判断节点
- 紫色：外部数据或外部系统
- 灰色虚线：规划能力
- 红色：人工处理或业务行动

## 后续重新排列

如果修改节点后需要重新生成布局，可在项目根目录执行：

```bash
node scripts/reflow-drawio.mjs
```

脚本会更新 7 张分图，并重新生成多页面汇总文件。
