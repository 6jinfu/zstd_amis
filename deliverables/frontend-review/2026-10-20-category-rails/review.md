# 分类及相近范围导航检查（2026-10-20）

本轮仅调整管理端桌面分类导航的尺寸与表现，保留现有业务行为和用户数据。当前 PRD V1.46。

## 统一规格

| 项目 | 原值 | 本轮 |
| --- | --- | --- |
| 类别 / 部门栏 | 208px | 192px |
| 岗位地图序列栏 | 246px | 192px |
| 详情分区栏 | 152px | 144px |
| 标准类别项纵向节奏 | 45–50px | 40px，无额外行间距 |
| 指标项纵向节奏 | 45px | 40px，无额外行间距 |
| 评估类别项纵向节奏 | 41px | 40px，无额外行间距 |
| 字号 / 行高 | 13–14px / 不同规格 | 13px / 20px |
| 树缩进 / 展开位 / 文字间距 | 14–22 / 14–24 / 4–8px | 16 / 16 / 4px |
| 选中反馈 | 竖线、透明、浅底混用 | 浅品牌蓝整行圆角底、蓝字 |

分类侧栏内边距12px 8px、标题行32px；统一中性悬停和键盘焦点，不额外添加图标。岗位地图去掉文件图标。层级叶子预留展开位，扁平列表不加空位，长指标名称可用title查看。公共指标选择弹窗和盘点选人组织栏使用192px / 40px；主设置编辑树保留全宽两层与行内操作，仅把52px行收至40px，保留文件夹与文件图标。

## 实际 Jev 判断

实际请求一次 TypeSafe System One，返回模型`jev-1.13.0`；输入1423 / 输出224 tokens。只发送匿名界面结构、尺寸及设计选项，没有发送用户的实际人才或岗位数据。请求与完整响应在同目录JSON中。

| 判断 | 返回选项 | 选项概率 / confidence |
| --- | --- | --- |
| 宽度 | 192px | 0.52 / 0.36；184px为0.44，接近 |
| 行密度 | 40px无外间距 | 0.81 / 0.72 |
| 覆盖范围 | 按角色共享规范 | 1.00 / 1.00 |
| 选中态 | 圆角整行浅底 | 0.99 / 0.98 |
| 层级 | 16px缩进与展开位 | 0.82 / 0.73 |

宽度分歧由实现者结合深层指标名称与“稍微窄一些”的要求裁定为192px。Jev是基于文字结构做选项判断，没有查看页面像素；其confidence不代表客观设计正确率，最终以浏览器检查为准。接口格式依据官方[Choice文档](https://docs.typesafe.ai/primitives/choice)。
