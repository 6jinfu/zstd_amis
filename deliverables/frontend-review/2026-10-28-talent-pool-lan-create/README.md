# 局域网人才池创建修复（2026-10-28）

## 复现与原因

在 `http://172.21.1.14:8766/talent-pool.html` 打开新建表单，填写名称、销售铁军来源项目，点击创建；弹窗保持打开，控制台报 `TypeError: crypto.randomUUID is not a function`，位置为talent-data.js原第14行。异常发生在记录创建前，未写入记录。

## 修复

仅修改共享记录编号函数：原生randomUUID存在时继续使用；否则使用getRandomValues生成16字节，设置UUID v4版本及变体位，保持prefix+UUID格式。没有更改业务字段、流程、历史数据或存储键。

- 新增两项Node回归：原生UUID优先调用、HTTP无randomUUID时1000个编号不重复且符合v4格式，并完成池与成员写入/读取；人才池共7项回归全部通过。
- 同一app文件用8770临时HTTP服务，在LAN IP访问（独立origin存储，避免污染8766用户数据）。中心创建销售经理后备人才池，组建赵颖1人，刷新后实际人数仍为1。
- 项目内创建技术骨干发展人才池，从本项目组建陈强1人，刷新后实际人数仍为1。两处均无控制台错误。
- 两处创建后截图已保存；验证标签关闭，临时服务停止。8766原有用户标签和未提交表单未改。
- 未在另一台物理电脑重复验证；本机采用同一局域网HTTP地址条件。
