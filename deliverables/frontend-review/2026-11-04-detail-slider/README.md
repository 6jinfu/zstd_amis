# 标准AI内容详略滑块

日期：2026-11-04。用户要求：用拖动滑块替代两项单选，左简洁、右详细，增加中间过渡词并细化样式；借鉴UI for AI。

## 实现与设计

采用简洁、精要、适中、充实、详细五档原生range；沿用现有蓝色与字体，细轨道、白色手柄、刻度文字、当前值及即时说明。支持真实拖拽、点击轨道和文字刻度、方向键与Home/End。拖动仅局部更新，不重绘对话；减少动态效果时关闭手柄过渡。生成设置和底部确认继续保留。

参考：[UI for AI — Design Principles for Future AI](https://medium.com/ui-for-ai/design-principles-for-future-ai-cebc9155745f)关于用户控制与明确系统边界的思路；本地采用design-taste-frontend技能细化控件，不安装第三方UI框架。

详略配置统一用于显示、生成记录和实际生成上限：能力5/6/7/8/10，其他四类2/2/3/4/5。仅截取已有可用内容，不为凑数新增；因此来源较少时相邻档位结果可能相同。沿用原简洁与常规上限，常规档显示名改为适中。未改Dify双档契约、未接真实模型。
