# 人才中心规范收敛与视觉复核

日期：2026-09-29。当前依据：用户最新明确要求、PRD V1.30 第 9、14 节、项目现有列表与详情页面。

## 使用方法与边界

应用本机 aiforui 对应的 Emil 设计基础、UI review 技能，按现有项目的布局、主次操作、字体、间距和控件做审查。TypeSafe 技能用于限制判断范围：明确规则直接核验，调整记录为保留、修改、移除；没有需求依据就不增加。以下为本地代码与界面的证据判断记录，不是 TypeSafe API 推理结果。本轮未调用付费 TypeSafe 服务或生图服务。

## 调整判断

| 对象 | 结论 | 依据 / 发现 | 落地 |
| --- | --- | --- | --- |
| 已保存视图 | 移除 | 用户明确指出前期没有此功能 | 删除入口、操作处理和初始数据字段；不删除浏览器已有其他数据 |
| 人才库表格 | 修改 | PRD 14.1 公共列表；此前多行信息过密 | 姓名、部门、岗位、分类、最近评鉴、操作单行展示；来源和在池信息在档案查看 |
| 筛选 / 批量操作 | 修改 | 公共筛选与操作区布局 | 部门侧栏、基础筛选、更多筛选、批量操作和导出分层，未选择时不显示“已选 0 人” |
| 档案标题与布局 | 修改 | PRD 14.3 详情结构；此前重复横幅与标题 | 返回、姓名、操作合并一栏；四个内容分区保留，字段统一三列 |
| 能力雷达与证据 | 保留并简化展示 | 当前需求要求真实能力与标准差距 | 雷达不随标准改变；统计改为要求、已满足、待发展、待补证据，缩短解释文案 |
| 人才池详情 | 修改 | 属性和成员挤在同一屏 | 基本信息、在池成员、跟进与历史分区，默认成员；编辑与导出集中顶栏 |
| 池编辑 / 入池 / 跟进 | 保留 | 已有需求与业务校验 | 沿用公共抽屉、表单、多选器；原去重、退出历史及复评规则保留 |
| 对比页 | 修改 | PRD 9.3 同标准比较 | 合并操作标题栏，统一选择器，简化说明，证据缺失仍独立显示 |
| 看板 | 修改 | 实测公共表格最小宽度挤出右侧卡片 | 网格允许收缩，局部表格不继承 880px 最小宽度；部门控件恢复标准宽度 |
| 切页过渡 | 修改 | 实际截图出现旧页淡入重影 | 仅人才页停用跨文档淡入，保留旧导航隐藏及键盘跳转入口修复 |
| 正式任用、个人计划执行等 | 不新增 | 当前阶段无对应后端和业务闭环 | 保持原型边界，不伪装为已实现 |

## 验证

- 浏览器检查六页的桌面布局，以现有标准列表为参照；本轮截图主要为 1280×720。
- 人才库：单行列表、部门和基础筛选、批量选择；张明和李华选中后进入对比。
- 对比：选择架构师标准，正确分开已满足、待发展和待补充证据。
- 档案：基本信息、雷达、证据表、四项统计；浏览器当前标准含 7 项，结果为 4 已满足 / 1 待发展 / 2 待补证据。
- 人才池：列表、成员、基本信息、跟进与退出历史；编辑抽屉打开并取消，不改已有成员记录。
- 看板：两列均在视口内；5 位人才、3 位有有效评鉴、2 位在池，与当前演示数据一致。
- talent-center.js、talent-data.js 语法检查通过；7 组业务规则检查通过；相关文件 diff 空白检查通过。
- 页面资源使用 20260929g，清除旧缓存版本影响。浏览器检查期间未发现 console error / warn。

本轮不代表后端、真实大数据量、多浏览器或移动端验收。打印和 CSV 的业务实现沿用前一轮，本轮没有重复验收最终文件。
