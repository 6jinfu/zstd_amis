能力编辑沿用手工新增标准的词条、等级下拉和移除控件，选择能力复用同一分类搜索穿梭选择器。

## 浏览器验证

- 初始三项：算法设计L4、模型工程L4、特征工程L3，无文本输入框。见 `editor.png`。
- 在副本中将算法设计改为L5、移除模型工程，选择器能看到正确的两项选择；选择器中移入新词条后取消，编辑列表仍为两项且保留L5。
- 取消外层编辑，再次打开恢复原三项及原等级，雷达图仍为L4/L4/L3。
- 名称搜索“协同”返回协同推进、组织协同；移入协同推进并确定后，回到原编辑抽屉，算法设计保留L5、新词条默认L3。见 `picker.png`。
- 点击更新草稿后，雷达图同步为算法设计L5、特征工程L3、协同推进L3。见 `updated-editor.png`（更新后再次打开编辑抽屉）。
- 已选两项时尝试移入整页二十项，提示“最多选择20项”，没有超出上限。
- 内层选择器按Esc回到外层编辑；外层编辑按Esc放弃本次修改，底层AI会话与原草稿保持可见。修正了原全局Esc会关闭底层会话的问题；保留原生dialog键盘行为。
- 独立打开已有标准的手工编辑页，能力选择器能正常打开、Esc关闭后回到原页面；没有保存或覆盖正式标准。
