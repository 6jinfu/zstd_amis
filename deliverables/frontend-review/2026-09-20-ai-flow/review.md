# AI 帮建生成后流程 UI 优化验收

日期：2026-09-20

## 方案与范围

使用 redesign-existing-projects、ui-review、forms-and-inputs skill，先检查原流程，再调整信息层级。原布局的主要问题是聊天气泡、吸附大卡挤占空间，而标准内容被限制在 353px 侧栏。

- 首页与公共顶栏保留原样，继续使用 75vw 抽屉。
- 发送后使用步骤条、居中建模表单，以及独立固定底栏。
- 结果页采用左侧标准文档与分项导航、右侧 288px 应用范围侧栏；反馈收纳为可展开区。
- 展示职责下任务明细、经历条目、能力等级、动力与潜力；不再堆叠重复确认气泡。
- 范围使用原生 radio，切换不重绘文档；反馈和范围互斥，按钮明确显示“按反馈重新生成”或“带入新建页”。

新增 `app/standard-ai-flow.css?v=20260920b`，仅列表页加载。交互脚本为 `standard-ai-assistant.js?v=20260920l`。未修改已有 `standards.css` 内容，其本轮前后 SHA-1 均为 `77cab77812cde36c4450f157734b76702a3d77d1`。未修改标准编辑器及无关页面。

## 验证结果

| 检查 | 结果 |
| --- | --- |
| 首页保护 | 浏览器比对顶栏、欢迎区、输入区共 40 个元素，内容、几何、计算样式完全一致；HTML 首页壳层未修改 |
| 新会话 | 岗位与输入清空、欢迎区恢复、生成阶段 class 移除 |
| 信息确认 | 岗位、层级、管理范围和场景调整反映到草稿；Tab 顺序与视觉顺序一致 |
| 表单校验 | 空场景显示行内错误并聚焦；五类全取消时阻止提交；只保留能力要求时仅生成该分项 |
| 长需求 | 3000 字需求预填完整保留；确认表单上限与首页一致 |
| 草稿内容 | 销售样例完整展示 3 项职责下 6 项任务，以及其余四类内容；分项跳转可用 |
| 范围切换 | 同类岗位对应销售经理、区域销售总监、大客户销售经理；键盘方向键可切到暂不关联；切换前后文档 scrollTop 均为 750 |
| 反馈分支 | 输入反馈清空范围，主按钮切为重新生成；重生成后场景包含反馈；清空反馈时无范围且带入禁用，重新选范围后恢复 |
| 草稿带入 | 同类岗位与暂不关联均在新建页正确映射，显示“AI 生成内容待确认”，未点击保存、未新增标准记录 |
| 岗位修改 | 修正原先按最初需求套用示例的问题；销售改为架构师后不再生成销售指标，无专用示例时回退通用内容 |
| 桌面布局 | 1280×720、1440×900、1920×1080 工作区无横向溢出；正文与侧栏独立滚动、底栏不遮挡内容 |
| 历史栏 | 生成后采用覆盖方式，1440 宽度下主文档区域打开前后均为 791px |
| 代码 | `node --check app/standard-ai-assistant.js`、`git diff --check` 通过；浏览器捕获的 error 日志为空 |
