# 旧导航清理与局域网闪现修复

日期：2026-10-28，PRD V1.85。

## 原因与处理

- 用户确认闪现旧导航/另一套布局。局域网响应内容与工作区文件SHA-256一致，返回no-store，未发现另一份旧服务器页面。
- 原32页HTML均保留旧顶部导航及侧栏，app.js再创建新版导航、克隆菜单并移动节点；人才页另以visibility补丁隐藏旧骨架。这条转换链已完全删除。
- 浏览器同时复现跨中心跳转被中止，错误为`ViewTransition opt-in disabled`：全站navigation:auto与人才页navigation:none混用。删除全站跨文档淡入、旧根节点动画及人才页覆盖后，相同跳转成功。
- 32页统一当前布局和主内容前的同步navigation.js，单一配置负责五个中心、业务菜单、设置分区、移动导航及当前折叠操作；链接基于脚本目录解析。移除旧导航专用CSS及旧骨架隐藏规则，不加等待定时器或新的隐藏补丁。
- 实现代码相对此轮修改前净减少563行（含新增38行navigation.js，不含测试及文档）；32页main内容逐一比对未变。保留既有业务、用户浏览器数据及其他工作区修改。

## 验证

- 局域网地址五中心跳转及人才库/人才池往返成功；设置页功能设置能切换到learner分区。
- 390px实测：移动导航flex、桌面侧栏none、旧导航节点0；人才库与人才池往返成功，临时尺寸已恢复。修后复查无控制台错误。
- 临时验证页沿用真实人才池页面与样式，将业务脚本延迟1.5秒；100帧采样中92帧在业务加载前、8帧在加载后，旧导航0帧，顶部位置始终为156,0,1116,49。结果见slow-script-result.json；临时页面已删除，不留业务入口。
- 11项Node回归覆盖菜单、设置锚点、嵌套/文件路径、折叠、32入口无旧结构及跨页过渡清理，以及人才池数据回归。5项资源/缓存回归、190段页面内联JS编译、292处资源指纹及diff空白检查通过。
