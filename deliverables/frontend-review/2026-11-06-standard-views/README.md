# 人才标准双视图核验

日期：2026-11-06。依据：[会议记录](https://feishu.doubao.com/docx/PmDnd56rEoJvW2xIT5fc0PQWnIh)，修订5；已阅读全文及双视角规则对比图。用户确认纪要中的“精能洞见”指经历、能力、动力、潜力，沿用现有内容，不另建模块。

## 本轮实现

- `standards.html` 与 `positions.html` 提供“按岗位查看 / 按标准查看”双视图入口，复用公共 `tab-btns/tab-btn` 和二级标签样式：选中实心品牌蓝、白字、圆角，不包外框、不加阴影；紧接顶部业务导航。
- 岗位列表原字段、筛选、关键/全部岗位切换及操作保留。岗位详情读取全部关联标准，支持新建标准及进入共用编辑页。
- 岗位入口新建默认关联当前岗位，可增加/移除岗位、切换关联方式；返回和取消回原岗位。标准编辑完整回显显式关联岗位，不按入口岗位裁剪。
- 保存指定岗位或暂不关联时清理该标准旧的额外岗位关系，避免另一视图残留；其他标准与学习方案记录保留。条件标准的普通内容编辑保留既有条件及额外关联。
- PRD V1.120 与 PROJECT_HANDOFF.md 已同步。
- 用户补充截图后，将关键/全部岗位切换固定在类别面板最顶部，位于标题和搜索之前；采用40px高、中性灰底、选中白底蓝字及斜切衔接，删除数量角标和浮起阴影。类别组件构造树内容时保留头部控件，搜索无结果不隐藏切换。
- 标签栏下方间距对齐指标库：去除原额外16px下外边距。指标库实际测量标签栏底部101px、工作区顶部101px，两视图复用同一0px外边距规则。
