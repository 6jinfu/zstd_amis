# 人才发展系统 · PRD 03 · 评鉴中心（测评 + 盘点）

> 一级模块 · Discover 阶段。评鉴中心 = 测评(取数) + 盘点(析数) 两个二级板块。
> 依赖：人才标准（测什么由标准决定）、关键岗位系数 · 下游：发展中心（差距驱动）、人才中心（沉淀）
> 数据归属：测评数据唯一归本模块（AssessmentResult），盘点只引用不另存。

---

## 0. 模块结构

```
评鉴中心
├── 测评（取数）
│   ├── 测评项目
│   ├── 测评任务
│   ├── 测评工具配置
│   └── 测评结果
└── 盘点（析数）
    └── 盘点项目（含向导/结果/校准）
```

职责边界：**测评产数据 → 盘点用数据**。测评只产单维度测量值；盘点整合测评+绩效+人员做透视/拟合。两者都项目制（遵循 00 §12A）。

# 第一部分 · 测评（取数）

## 1. 测评目标

按"测评 = 测标准的结构"原则，对员工就其所在组的标准维度进行测量，产出结构化测评值，供盘点消费。测评以**测评项目**为组织单位，可独立创建、独立排期、独立跑完；结果沉淀后可被多个盘点项目引用。

> 核心：标准有几个维度就测几个维度，测法由维度性质反查自动匹配。

## 2. 测法体系（由标准维度反查）

| 标准维度 | 归属 | 测量主体/手段 | 数据性质 |
| --- | --- | --- | --- |
| 任务（任） | 任职 | 领导测，或**优先直接引用绩效** | 任务类 |
| 经历 | 资格 | HR/领导**核验**（事实核验，非打分） | 事实类 |
| 专业能力 | 资格 | 考试 / 情景模拟 / 实操 | 行为类 |
| 通用能力 | 资格 | 360 | 行为类 |
| 动力 | 资格 | 心理测评问卷（沙因模型） | 心理类 |
| 潜力 | 资格 | 心理测评问卷（大五人格） | 心理类 |

> 归类记忆：任务类→引绩效；事实类→核验；行为类→考试/情景/360；心理类→标准化测评问卷。

## 4. 评价者配置（按测法）

| 测法 | 评价者 | 说明 |
| --- | --- | --- |
| 360 | 自评+上级+同级+下级 | 多反馈源，记 rater_source；需**反馈源指派**子页（谁评谁） |
| 考试/情景 | 系统判分/考官 | 专业能力 |
| 心理测评 | 被测本人填问卷 | 动力/潜力 |
| 领导测/引绩效 | 直接上级 / 系统引绩效 | 任务 |
| HR核验 | HR/领导 | 经历，事实核验 |

## 5. 混合式评价（国企述职场景）★

`input_mode = blended` 时：线下品鉴/述职 → 评委人工打分 → 分数导回系统 → 写入 AssessmentResult。
- 结果录入方式，非新测法；支持批量导入（模板：员工×指标×分数）；与在线测评同等参与盘点。

## 6. 测评流程（项目制四步）

```
① 创建项目：名称/目标/周期/负责人
② 选择对象：圈定被测员工 → 读取其所在组标准维度
③ 选择维度：勾选要测维度（系统反查测法）
④ 选择工具：每维度配工具 + 评价者(360需指派反馈源) + 输入模式
──────────────────────────────────
⑤ 运行：生成测评任务下发（在线作答/混合导回/引绩效自动拉）
⑥ AI 信度检验
⑦ 汇总写入 AssessmentResult → 供盘点引用
```

> 测评无"矩阵组合/校准"扩展步。任务维度优先引绩效（责对接"绩"、任对接"效"），打通绩效数据链。

## 7. 测评↔盘点的引用关系

| 路径 | 触发 | origin | 说明 |
| --- | --- | --- | --- |
| 独立跑（主路径） | 评鉴中心直接建测评项目并执行 | standalone | 结果供任意盘点勾选引用 |
| 盘点发起（补充） | 盘点向导"新建补测" | from_review | 评鉴中心执行、数据归此，完成回流 |

测评项目详情展示"被哪些盘点引用"（反查）。覆盖度由盘点侧检查（见 §13.4）。

# 第二部分 · 盘点（析数）

## 8. 盘点目标

人才盘点**按"盘点项目"实施**：每次 = 独立项目实例，可多次开展、可追溯、可对比历次。整合上游数据透视/拟合，产出：①人才清单/HiPo（T值排序）②组织规律（组织故事）③逐维度差距（驱动培养）。

> 本质：盘点 = Excel 透视表 + 图表，系统一键呈现。值钱的是规则配置与数据贯通。

## 9. APP 数据模型（数据源三类，可选组合）

| 字母 | 数据类 | 内容 | 必选 |
| --- | --- | --- | --- |
| **A** | Assessment 测评 | 能力/动力/潜力测量值（来自测评） | 可选 |
| **P** | Performance 绩效 | 历年绩效（绩效系统） | 可选 |
| **P** | People 人员 | 工号/性别/学历/司龄/年龄 | **必选** |
| —加权 | 关键岗位系数 | 岗位中心诊断 | 可选加权 |

## 12. 盘点规则引擎（三层，核心壁垒）

### 12.1 人才值规则（T值排序）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| weights | object | 可配权重（能力50%+动力30%+潜力20%） |
| key_position_coef_on | bool | 叠加关键岗位系数 |
| formula | 系统 | T = Σ(维度值×权重) ×(关键岗位系数?) |

### 12.2 分析规则（交叉）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| cross_type | enum | A / A×P绩效 / A×P人口 / P×P |
| x_var / y_var | ref | X/Y 变量 |
| present_type | enum | 九宫格 / 拟合 / 分布图 |

### 12.3 呈现规则

**九宫格 GridRule**：axis_x/y、x/y_thresholds（分档阈值）、cell_labels（9格命名）、internal_corr_warning。
**拟合 FitRule**：x_var/y_var（建议独立）、fit_type（线性/倒U/多项式）、correlation。

### 12.4 经典组合模板（一键套用）★

| 模板名 | X | Y | 看什么 | 呈现 | 内生相关 |
| --- | --- | --- | --- | --- | --- |
| 经典九宫格 | `perf.current` | `assess.potential` | 谁是高潜 | 九宫格 | ⚠️ |
| 能力-绩效格 | `assess.t_value` | `perf.current` | 能力转化业绩 | 九宫格/散点 | 中 |
| 天花板效应 | `people.age` | `assess.general_ability` | 组织老化 | 拟合(倒U) | 无 |
| 培养见效 | `people.tenure` | `assess.t_value` | 老人是否更强 | 拟合 | 无 |
| 新人拐点 | `people.tenure` | `perf.avg` | 3年拐点 | 拟合 | 无 |
| 心力矩阵 | `assess.motivation` | `assess.general_ability` | 有心无力 | 九宫格 | 无 |
| 高潜留存 | `people.tenure` | `assess.potential` | 高潜留得住吗 | 散点 | 无 |
| 关键岗位厚薄 | `derived.key_pos_coef` | `assess.t_value` | 关键岗位储备 | 散点/分布 | 无 |

### 13.4 历次对比

支持选 2+ 历次盘点项目，对比同一人才/组的 T值、分类、分布变化（趋势）。

## 14. 盘点流程（四步 + 盘点扩展两步）

```
① 创建项目 ② 选对象+标准 ③ 选维度(APP全集) ④ 选工具(数据源:引用/新建+就绪度检查)
⑤ 矩阵组合(人才值/分析/呈现，套模板) → 生成结果
⑥ 校准(解释默认/人工校准留痕)
⑦ 输出 → 人才池 / 组织看板 / 差距驱动发展中心
```

## 15. AI 能力

测评：信度检验。盘点：T值权重建议、九宫格阈值建议、交叉维度推荐、内生相关检测。

## 16. 验收要点

- [ ] 评鉴中心含测评(项目/任务/工具/结果) + 盘点(项目) 两板块。
- [ ] 测评项目制四步；360 有反馈源指派；支持混合导入；可引绩效。
- [ ] 测评结果唯一归 AssessmentResult；项目可被多盘点引用。
- [ ] 盘点项目制六步；APP people必选、测评/绩效可组合。
- [ ] 测评纳入两路径（引用/新建）+ 对象覆盖度检查 + 就绪度门槛。
- [ ] 字段全集带元数据约束选项；经典组合可套用。
- [ ] 三层规则引擎；T值可加关键岗位系数；九宫格内生相关提示；拟合支持倒U。
- [ ] 输出差距驱动培养；解释默认/校准留痕；支持历次对比。
