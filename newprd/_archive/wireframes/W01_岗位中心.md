# 线框说明 W01 · 岗位中心（页面级字段/组件）

> 对应 PRD 01 + 08。逐页给出：布局、字段、表格列、按钮、交互。
> 组件/视觉遵循 07；布局骨架遵循 00 §14；状态/项目范式遵循 00 §12/§12A。
> 标注：`[btn]`按钮 `[col]`表格列 `[field]`表单字段 `[tag]`状态标签 `→`跳转。

---

## 1. 组织结构 · 序列×层级矩阵 `/position/org-matrix`

**布局**：面包屑 + 标题行（右侧 `[btn]切换人效视图`）+ 矩阵卡片。

**矩阵**：行=序列，列=层级；表头行/列可编辑（→序列层级维护）。
- 单元格（每个=一个组 Group）显示：组名、岗位数、在岗人数。
- `[交互]` 点单元格 → 组详情页。
- 空单元格（无组）显示"＋ 建组"。

**人效视图开关**：切换后单元格追加显示 人数 / 人力成本 / 人均成本 / 利润贡献（来自外部导入）。

---

## 2. 组详情 `/position/org-matrix/group/{id}`

**布局**：返回 + 组名标题 + 两个区块。
- **区块A 归属岗位**：表格 `[col]`岗位名 / 部门 / 编制数 / 关键岗位`[tag]` / 操作。
- **区块B 关联标准**：显示该组标准完整度`[tag]`（基础/完整）+ `[btn]编辑标准` → 模型库组标准编辑。

---

## 3. 岗位管理 · 岗位列表 `/position/positions`

**筛选区**：`[field]`岗位名 + `[field]`所属组(下拉) + `[field]`是否关键岗位(下拉) + `[btn]查询` `[btn]重置`。
**主操作**：`[btn]新增岗位` `[btn]批量导入`。
**表格列**：`[col]`岗位名 / 所属组(序列×层级) / 部门 / 编制数 / 关键岗位`[tag]` / 关键岗位系数 / 状态`[tag]` / 操作(编辑·删除)。
**分页**：共N条 / 每页 / 页码 / 前往。

### 3.1 岗位编辑 `/position/positions/{id}`
表单字段：`[field]`岗位名✅ / `[field]`归属组✅(选择器，提示"按职级归组") / `[field]`部门 / `[field]`编制人数 / `[field]`状态。
只读显示：关键岗位标记、系数（由诊断回写，不可手填）。

---

## 4. 岗位序列维护 `/position/sequences`

**左**：序列列表（`[btn]新增序列`，行内编辑名称/排序/状态）。
**右**：层级列表（`[btn]新增层级`，字段：名称、rank 职级序号✅、状态）。
说明文案：序列×层级自动生成组。

---

## 5. 关键岗位诊断 · 项目列表 `/position/diagnoses`

**主操作**：`[btn]创建诊断项目`。
**表格列**：`[col]`项目名 / 目标 / 岗位范围(数量) / 选用视角(B/E/A/R/S) / 创建时间 / 状态`[tag]`(draft/running/done) / 负责人 / 操作。
- 操作随状态：draft→编辑/删除；running→查看/终止；done→查看结果/归档。

### 5.1 诊断向导（步骤条：①创建 ②选岗位 ③选视角 ④打分）
- **①创建**：`[field]`项目名✅ / `[field]`目标✅(GPS-Goal) / `[field]`负责人 / `[field]`周期。
- **②选岗位**：穿梭框选岗位清单（Start Point 提示"岗位需先梳理"）。
- **③选视角**：勾选 BEARS（B业务/E经济/A能力/R变革/S战略），多选；每个视角旁有方法说明 tooltip。
- **④打分**：按视角×岗位的打分表格，`[col]`岗位 / 各视角分 / 循证依据(evidence) / `[btn]AI建议分`。
- 底部 `[btn]上一步` `[btn]下一步` `[btn]运行诊断`。

### 5.2 诊断结果 `/position/diagnoses/{id}/result`
- **视角权重配置**：各视角权重滑块（默认等权，可调）。
- **关键岗位清单表**：`[col]`岗位 / 综合系数 / 是否关键`[tag]` / 发展优先级。
- **气泡图**：X需求度 × Y供给量，红泡/灰泡，气泡大小=人数。
- `[btn]回写岗位`（确认后写 key_position_flag/coef）。

## 6. 指标库 · 指标列表 `/position/indicators`

**筛选区**：`[field]`指标名称 + `[field]`类型(全部/能力/任务/资格) + `[btn]查询`。
**主操作**：`[btn]新增指标` `[btn]词典管理`。
**表格列**：`[col]`指标名称 / 分类 / 类型 / 行为项(N条/—) / 操作(编辑·删除)。

### 6.1 指标编辑 `/position/indicators/{id}`
表单：`[field]`名称✅ / `[field]`分类✅(能力/任务/资格) / `[field]`类型✅(随分类联动) / `[field]`测量手段✅(随类型联动) / `[field]`量表✅ / `[field]`定义✅ / `[field]`词典引用 / `[field]`外部工具(动力潜力类) / `[field]`状态。
- **行为项子表**（仅能力类）：`[col]`等级(L1–L5) / 行为描述(动词+宾语,AI校验) / 锚定示例；`[btn]新增行为项`。
- **任务类**：改显示绩效对接字段（结果指标/过程指标）。

### 6.2 词典管理 `/position/indicators/dict`
术语列表 + 增删改，统一口径。

---

## 7. 模型库 · 组标准列表 `/position/models`

**表格列**：`[col]`组(序列×层级) / 完整度`[tag]`(基础/完整) / 引用指标数 / 关联人数 / 操作(编辑)。

### 7.1 组标准编辑 `/position/models/{groupId}`
**布局**：左结构树（任职 / 资格）+ 右表单。
- **任职页**：责-任树。责`[field]`名称 + 绑定绩效"绩"结果指标；任`[field]`名称(动词+宾语,AI校验) + 绑定绩效"效"过程指标。`[btn]加责` `[btn]加任`。
- **资格页**：4D（经历/能力(通用·专业)/动力/潜力）。每项 `[field]`引用指标(选择器) + `[field]`标准值required_level + `[field]`权重weight。
- 完整度实时提示；非必填可空，不阻断保存。
