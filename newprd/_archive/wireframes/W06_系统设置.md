# 线框说明 W06 · 系统设置（页面级字段/组件）

> 对应 PRD 00 §16 + 08。标注：`[btn]`按钮 `[col]`列 `[field]`字段 `[tag]`状态。

---

## 1. 用户与权限

### 1.1 用户列表 `/settings/users`
**筛选**：`[field]`姓名/账号 + `[field]`角色 + `[field]`状态 + `[btn]查询`。
**主操作**：`[btn]新增用户` `[btn]批量导入`。
**表格列**：`[col]`姓名 / 账号 / 角色 / 部门 / 状态`[tag]` / 操作(编辑·停用)。

### 1.2 角色权限配置 `/settings/roles`
- 角色列表（sys_admin/hr_admin/biz_leader/employee/executive）。
- 权限矩阵：`[col]`模块/页面 × 操作(查看/增/改/删) 勾选。
- 数据范围：`[field]`行级(本人/本部门/全组织) + `[field]`字段级敏感字段隐藏(潜力/薪酬/人效)。

---

## 2. 组织与人员 `/settings/org`
- 组织架构树（部门）+ 员工列表。
- `[btn]导入员工`（模板）+ 校验预览 + 确认。
- 员工字段：工号/姓名/性别/学历/司龄/年龄/部门/岗位/组。

---

## 3. 词典管理 `/settings/dict`
- 全局术语列表 + 增删改，统一各模块口径。
- `[col]`术语 / 分类 / 说明 / 操作。

---

## 4. 外部工具对接 `/settings/integrations`
分组配置卡：
- **测评量表**：心理测评(大五/沙因)等外部量表绑定 `[field]`API/密钥。
- **绩效系统**：绩效数据源对接（供任务维度引绩效）。
- **LD 学习平台**：课程库/培训项目对接（供培养形式接入）。
- 每项 `[btn]测试连接` + 状态`[tag]`。

---

## 5. AI 设置 `/settings/ai`
- AI 建议总开关。
- 场景开关表：`[col]`场景(关键岗位打分/描述校验/T值权重/九宫格阈值/交叉推荐/信度检验/培养形式推荐) / 启用 / 说明。
- 统一接口说明：`POST /api/ai/suggest`（给建议不给结论，用户确认才落库）。
