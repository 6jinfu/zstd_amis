# 线框说明 W02 · 评鉴中心（测评 + 盘点 · 页面级字段/组件）

> 对应 PRD 03 + 08。评鉴中心 = 测评(取数) + 盘点(析数) 两个二级板块。
> 组件遵循 07，布局遵循 00 §14，项目范式遵循 00 §12A。
> 标注：`[btn]`按钮 `[col]`列 `[field]`字段 `[tag]`状态 `→`跳转。

---

# A. 测评板块

## A1. 测评项目 · 列表 `/review-center/assessment/projects`
**筛选**：`[field]`项目名 + `[field]`状态 + `[field]`面向组 + `[btn]查询` `[btn]重置`。
**主操作**：`[btn]创建测评项目`。
**表格列**：`[col]`项目名 / 面向组 / 维度数 / 完成度(已测/总) / 创建时间 / 状态`[tag]` / 负责人 / 操作。

### A1.1 测评项目向导（①创建 ②选对象 ③选维度 ④选工具）
- ①创建：`[field]`项目名✅/目标✅/周期/负责人。
- ②选对象：穿梭框选员工 → 读取所在组标准维度。
- ③选维度：勾选要测维度；标注反查测法。
- ④选工具：每维度 `[field]`工具(按测法过滤) + `[field]`评价者 + `[field]`输入模式。
  - **L3 360 反馈源指派弹窗**：为每个被测对象指派 自评/上级/同级/下级 名单。

### A1.2 测评项目详情 `/assessment/projects/{id}`
- 头部：信息 + 完成度进度条 + `[btn]催办未完成`。
- 【列表】任务列表（→任务页）。
- 【列表】被引用区：引用本项目的盘点项目（反查）。

## A2. 测评任务
### A2.1 任务列表 `/assessment/projects/{id}/tasks`
`[col]`任务名/对象数/维度/工具/origin(独立/盘点发起)/状态/操作。
- 引绩效维度行标注"自动拉绩效，无需作答"。

### A2.2 作答页 `/assessment/tasks/{id}/answer`
题目/问卷/量表渲染（按工具类型）+ `[btn]保存草稿` `[btn]提交`。

### A2.3 混合导入弹窗 `/assessment/tasks/{id}/import`
`[btn]下载模板` + 上传 + 校验预览 + `[btn]确认导入`。

## A3. 测评工具配置 `/review-center/assessment/tools`
**主操作**：`[btn]新增工具`。
**表格列**：`[col]`工具名/测法/适用维度/量表/外部量表/状态/操作。
### A3.1 工具编辑 `/assessment/tools/{id}`
`[field]`名称✅/测法✅/适用维度✅/量表✅/外部量表/状态。

## A4. 测评结果 `/review-center/assessment/results`
**筛选**：`[field]`员工 + `[field]`维度 + `[field]`项目 + `[btn]查询`。
**表格列**：`[col]`员工/指标/维度/分值/评价来源/信度标记`[tag]`/任务。信度异常行高亮。

# B. 盘点板块

## B1. 盘点项目 · 列表 `/review-center/review/projects`
**筛选**：`[field]`项目名 + `[field]`状态 + `[field]`负责人 + `[btn]查询`。
**主操作**：`[btn]创建盘点项目`。
**表格列**：`[col]`项目名/对象数/标准/就绪度`[tag]`(ready/pending)/创建时间/状态`[tag]`/负责人/操作。
- 操作含 `[btn]查看结果` `[btn]历次对比`。

## B2. 盘点向导（6 步）
### ①创建 `/review/projects/new`
`[field]`项目名✅/目标✅/周期/负责人。
### ②选对象+标准 `/{id}/step-scope`
`[field]`对象✅(穿梭，可从群组/池导入) + `[field]`盘点标准✅。
### ③选维度 `/{id}/step-dimensions`
维度选择器（测评/绩效/人员/衍生 分组）+ 元数据角标(连续/类别/可拟合) + 建议纳入高亮。
### ④选工具(数据源) `/{id}/step-sources`
- People `[tag]`必选 / Performance `[field]`开关 / Assessment每维度 `[field]`(引用项目/新建补测) / 关键岗位系数 `[field]`开关。
- **就绪度检查区**：覆盖度(已覆盖/总)，缺失列 missing_employees + `[btn]补测` `[btn]留空跑`。
- 全 ready 才 `[btn]下一步`。
### ⑤矩阵组合 `/{id}/step-matrix`
- 人才值规则：各维度 `[field]`权重滑块 + `[field]`关键岗位系数开关 + T值公式。
- 分析规则：`[btn]套用经典组合模板` 或自定义 `[field]`X/`[field]`Y/`[field]`呈现；类别字段禁拟合；内生相关 inline warning。可加多组。
- 呈现规则：九宫格`[field]`阈值+9格命名；拟合`[field]`类型。
- `[btn]生成盘点结果`。
### ⑥校准 `/{id}/calibrate`
见 B3 校准区。

## B3. 盘点结果 `/review/projects/{id}/result`
- KPI 卡：盘点人数/HiPo数/平均T值/关键岗位覆盖率。
- 【列表】人才清单：`[col]`员工/组/T值/排名/人才分类`[tag]`。
- 图表区：九宫格(点格→**L3 格内人员弹窗**)/拟合(相关系数)/分布。九宫格内生相关 inline warning。
- 组织规律区：org_insights 文字结论。
- 差距区：逐员工逐维度 标准vs实测 gap。
- 校准区：`[field]`模式(解释/校准) + 校准 `[field]`理由 + 留痕(改前改后)。
- `[btn]沉淀人才池` `[btn]推差距到发展中心` `[btn]结论入组织看板`。

## B4. 历次对比 `/review/compare`
- `[field]`选 2+ 历次盘点项目。
- 【列表/图表】同一人才/组的 T值、分类、分布的历次变化（趋势）。
