# 人才发展系统 · PRD 08 · 完整页面清单（严格分层 · 无遗漏）

> 面向 AI / 前端：完整列出全系统页面，严格区分层级与页面内构成。
> 字段细节以 `features/F01–F14` 为准；07 看视觉；00 §12A 看项目范式。

## 分层定义（开发须遵守）

| 层级 | 定义 | 典型形态 |
| --- | --- | --- |
| **L0 一级模块** | 顶部一级导航项 | 模块入口 |
| **L1 一级页面** | 左侧二级菜单点入的主页面 | 列表 / 看板 |
| **L2 二级页面** | 从 L1 进入的子页面 | 详情 / 编辑 / 向导 / 结果 |
| **L3 三级页面/弹窗** | 从 L2 再进入的 | 向导步 / 子弹窗 / 导入框 / 子标签 |

页面内构成统一标注：**【列表】**含列、**【表单】**含字段、**【操作】**含按钮。
路由为建议值，`{id}` 为占位。

## 全局框架（所有页面共享）

- 顶部栏：Logo + L0 一级导航 + 通知 + 用户。
- 左侧栏：当前模块的二级菜单（分组+子项）。
- 内容区：面包屑 + 页面主体。

L0 一级导航：`岗位中心 / 评鉴中心 / 发展中心 / 人才中心 / 系统设置`

# L0-1 岗位中心 `/position`

## L1-1.1 组织结构（矩阵看板）`/position/org-matrix`
- 【列表】序列×层级矩阵，单元格=组（组名/岗位数/在岗人数）。
- 【操作】切换人效视图、点单元格→L2、空格建组。
- **L2-1.1.1 组详情** `/org-matrix/group/{id}`：【列表】归属岗位（岗位名/部门/编制/关键岗位标记）；【表单】关联标准完整度；【操作】编辑标准→L2-1.5.1。
- **L3-1.1.2 建组弹窗**：【表单】序列+层级。

## L1-1.2 岗位管理（列表）`/position/positions`
- 【列表】岗位名/所属组/部门/编制/关键岗位/系数/状态。
- 【操作】新增、批量导入、查询/重置、行内编辑/删除。
- **L2-1.2.1 岗位编辑** `/positions/{id}`：【表单】岗位名✅/归属组✅/部门/编制/状态；只读：关键岗位系数。
- **L3-1.2.2 批量导入弹窗**：【操作】下载模板/上传/校验预览/确认。

## L1-1.3 岗位序列（列表+配置）`/position/sequences`
- 【列表】序列列表 + 层级列表。
- 【表单】序列(名称/排序/状态)、层级(名称/rank✅/状态)。
- 【操作】新增序列、新增层级、行内编辑。

## L1-1.4 关键岗位诊断（项目列表）`/position/diagnoses`
- 【列表】项目名/目标/岗位范围/视角/创建时间/状态/负责人。
- 【操作】创建诊断项目、查看/编辑/删除/终止/归档（随状态）。
- **L2-1.4.1 诊断向导** `/diagnoses/new`：
  - L3 步骤页：①创建【表单】②选岗位【列表穿梭】③选视角【勾选BEARS】④打分【列表：岗位×视角分+循证+AI建议】。
- **L2-1.4.2 诊断结果** `/diagnoses/{id}/result`：【表单】视角权重；【列表】关键岗位清单；图表：气泡图；【操作】回写岗位。

## L1-1.5 指标库（列表）`/position/indicators`
- 【列表】指标名称/分类/类型/行为项/操作。
- 【操作】新增指标、词典管理、按名称+类型筛选。
- **L2-1.5.1 指标编辑** `/indicators/{id}`：【表单】名称✅/分类✅/类型✅/测法✅/量表✅/定义✅/词典/外部工具/状态；【列表】行为项子表(能力类)。
- **L2-1.5.2 词典管理** `/indicators/dict`：【列表】术语/分类/说明/操作。

## L1-1.6 模型库（组标准列表）`/position/models`
- 【列表】组/完整度/引用指标数/关联人数/操作。
- **L2-1.6.1 组标准编辑** `/models/{groupId}`：左树(任职/资格)+右表单。
  - L3 任职页：【列表】责-任树；【表单】责(名称+绩效绩)、任(动词+宾语+绩效效)。
  - L3 资格页：【表单】4D 各项(引用指标+标准值+权重)。

# L0-2 评鉴中心 `/review-center`

> 两个二级板块：**测评(取数)** + **盘点(析数)**。左侧栏用两个分组标题。

## 板块一 · 测评

### L1-2.1 测评项目（项目列表）`/review-center/assessment/projects`
- 【列表】项目名/面向组/维度数/完成度/创建时间/状态/负责人。
- 【操作】创建测评项目、查看/编辑/删除/终止/归档。
- **L2-2.1.1 测评项目向导** `/new`：L3 步骤页 ①创建②选对象③选维度④选工具。
  - **L3-2.1.1a 360 反馈源指派弹窗**：为被测对象指派自评/上级/同级/下级。
- **L2-2.1.2 测评项目详情** `/{id}`：【表单】信息+完成度+催办；【列表】任务列表、被引用盘点列表。

### L1-2.2 测评任务（列表，项目下）`/review-center/assessment/projects/{id}/tasks`
- 【列表】任务名/对象数/维度/工具/origin/状态/操作。
- **L2-2.2.1 作答页** `/assessment/tasks/{id}/answer`：【表单】题目/问卷/量表；【操作】保存草稿/提交。
- **L3-2.2.2 混合导入弹窗** `/import`：模板/上传/预览/确认。

### L1-2.3 测评工具配置（列表）`/review-center/assessment/tools`
- 【列表】工具名/测法/适用维度/量表/外部量表/状态/操作。
- **L2-2.3.1 工具编辑** `/{id}`：【表单】名称✅/测法✅/适用维度✅/量表✅/外部量表/状态。

### L1-2.4 测评结果（查询列表）`/review-center/assessment/results`
- 【列表】员工/指标/维度/分值/评价来源/信度标记/任务；信度异常高亮。

## 板块二 · 盘点

### L1-2.5 盘点项目（项目列表）`/review-center/review/projects`
- 【列表】项目名/对象数/标准/就绪度/创建时间/状态/负责人。
- 【操作】创建盘点项目、查看结果/历次对比/编辑/删除/归档。
- **L2-2.5.1 盘点向导**（6 步，每步 L3）：
  - L3 ①创建 `/new`：【表单】项目名✅/目标✅/周期/负责人。
  - L3 ②选对象+标准 `/{id}/step-scope`：【穿梭】对象(可从群组/池导入)+【表单】标准。
  - L3 ③选维度 `/{id}/step-dimensions`：【列表】APP字段(分组+元数据角标)勾选。
  - L3 ④选工具 `/{id}/step-sources`：【表单】People必选/Performance/Assessment(引用/新建)/关键岗位系数；【列表】就绪度覆盖表(缺失+补测/留空)。
  - L3 ⑤矩阵组合 `/{id}/step-matrix`：【表单】人才值权重、分析规则(套模板/X·Y·呈现)、呈现规则(阈值/拟合类型)。
  - L3 ⑥校准 `/{id}/calibrate`：见结果页校准区。
- **L2-2.5.2 盘点结果** `/{id}/result`：KPI卡；【列表】人才清单；图表(九宫格/拟合/分布)；组织规律；【列表】差距；校准区；【操作】沉淀人才池/推差距/入看板。
  - **L3-2.5.2a 九宫格格内人员弹窗**：点格看落在该格的人员清单。
- **L2-2.5.3 历次对比** `/review-center/review/compare`：【表单】选2+历次项目；【列表/图表】T值/分类/分布的历次趋势。

# L0-3 发展中心 `/develop`

## L1-3.1 岗位学习方案（列表）`/develop/plans`

## L1-3.2 岗位地图（列表）`/develop/position-maps`
- 【列表】岗位/组/阶段数/状态/操作。
- **L2-3.2.1 地图编辑** `/position-maps/{id}`：【表单】关联组/隐喻；【列表】阶段×目标×形式；预览路径图。

## L1-3.3 职级地图（列表）`/develop/level-maps`
- 【列表】序列/跃迁数/状态/操作。
- **L2-3.3.1 跃迁编辑** `/level-maps/{sequenceId}`：【列表】from→to层级/跃迁差维度/目标×形式；【操作】AI识别跃迁差。

## L1-3.4 个人发展计划 IDP（列表）`/develop/idps`

## L1-3.5 培养项目（项目列表）`/develop/projects`

- **L2-3.5.2 培养项目跟踪** `/projects/{id}/tracking`：KPI卡；【列表】成员进度(各形式完成/结业)；【操作】批量写IDP/发起结业复测。

## 跨模块流转图

```
岗位中心：组织结构/岗位 → 关键岗位诊断 →(回写系数)

评鉴中心·测评：测评项目 → 测评结果 ──引用──┐      │
评鉴中心·盘点：盘点项目 ①→②→③→④(引用测评)→⑤→结果→⑥校准
          产出：人才清单 / 组织规律 / 差距
                 │           │          │
人才中心：人才池/列表←┘  组织看板←┘      │
发展中心：IDP / 培养项目 ←──────────────┘(差距驱动)

人才中心：胜任看板 ←(标准+测评+差距+IDP)
```
