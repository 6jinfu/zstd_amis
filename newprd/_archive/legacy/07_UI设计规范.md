# 人才发展系统 · PRD 07 · UI 设计规范

> 面向 AI / 前端开发的统一视觉与布局契约。所有模块（01–06）的界面实现须遵守。
> 与 00 第二部分（命名/状态机/交互骨架）互补：00 定"页面有哪些区块"，本文定"长什么样、用什么色、什么间距"。
> 主色：蓝色系。整体形态：B 端后台管理系统——顶部一级导航 + 左侧分组菜单 + 内容区。

---

## 1. 设计原则

| 原则 | 落地 |
| --- | --- |
| 专业藏后台、大白话前台 | 界面文案口语化，专业理论放 tooltip/帮助（页面文案标注约定见 00 §19：注解不上页面、页面文案从简） |
| 信息密度优先 | B 端后台以表格/表单为主，紧凑但不拥挤 |
| 结构化降低认知负载 | 用分组、留白、层级引导视线 |
| 一致性高于个性 | 同类页面同一套布局，组件不自定义变体 |
| 数据可读性第一 | 看板/图表的配色服务于"一眼看懂规律" |

## 2. 整体框架布局

```
┌─────────────────────────────────────────────────────────┐
│  顶部栏 TopBar  [Logo] [一级导航…]      [通知][用户▾]      │  高 56px
├──────────┬──────────────────────────────────────────────┤
│ 左侧导航  │  内容区 Content                                │
│ SideNav  │  ┌────────────────────────────────────────┐  │
│          │  │ 面包屑 Breadcrumb                        │  │
│ 分组1     │  ├────────────────────────────────────────┤  │
│  ├子项    │  │ 页面主体（列表/表单/看板）               │  │
│  └子项    │  │                                        │  │
│ 分组2     │  └────────────────────────────────────────┘  │
│  └子项    │                                              │
│ 宽 220px  │  内容区左右留白 24px                          │
└──────────┴──────────────────────────────────────────────┘
```

### 2.1 顶部栏 TopBar

| 项 | 规范 |
| --- | --- |
| 高度 | 56px，固定吸顶 |
| 内容 | 左：Logo + 系统名；中/左：一级导航（模块切换）；右：通知铃、用户头像下拉 |
| 背景 | 白色或主色深色版（二选一，全局统一） |

一级导航 = 模块级：`岗位中心 / 测评中心 / 盘点中心 / 发展中心 / 人才中心 / 系统设置`。

### 2.2 左侧导航 SideNav

| 项 | 规范 |
| --- | --- |
| 宽度 | 展开 220px，折叠 56px（仅图标） |
| 结构 | 分组标题（不可点，灰字）+ 其下子菜单项（可点） |
| 选中态 | 主色文字 + 主色浅底（`primary-50`）+ 左侧 3px 主色竖条 |
| 悬停态 | 浅灰底 `neutral-100` |

> 子项为当前模块的二级/三级页面。示例（岗位中心）：分组"岗位管理"→ 岗位列表/岗位序列；分组"词典库"→ 指标库/模型库。

### 2.3 内容区

| 项 | 规范 |
| --- | --- |
| 顶部 | 面包屑（模块 / 当前页），灰字 13px |
| 留白 | 上下 16px，左右 24px |
| 背景 | 浅灰 `neutral-50`，内容卡片白底 |

### 3.2 中性色

| Token | 值 | 用途 |
| --- | --- | --- |
| `neutral-900` | `#1F2937` | 主文字 |
| `neutral-600` | `#4B5563` | 次文字 |
| `neutral-400` | `#9CA3AF` | 占位符/禁用文字 |
| `neutral-200` | `#E5E7EB` | 边框/分隔线 |

| `neutral-50` | `#F9FAFB` | 页面背景 |
| `white` | `#FFFFFF` | 卡片/表格底 |

### 3.3 状态色（语义）

| Token | 值 | 用途 |
| --- | --- | --- |
| `success` | `#16A34A` | 成功、达标、完成 |
| `warning` | `#F59E0B` | 警告、进行中 |
| `danger` | `#DC2626` | 错误、删除、差距大 |
| `info` | `#0EA5E9` | 提示、信息 |

### 3.4 业务语义色（本系统专属，必须固定）★

| 场景 | 含义 | 色 |
| --- | --- | --- |
| 气泡图·红泡 | 需求高·供给少（优先培养） | `danger` `#DC2626` |
| 气泡图·灰泡 | 需求低·供给多（去招聘） | `neutral-400` `#9CA3AF` |
| 胜任度·达标 | 实测 ≥ 标准 | `success` `#16A34A` |
| 胜任度·差距 | 实测 < 标准 | `warning`→`danger` 按差距深浅 |
| 人才分类·HiPo | 高潜 | `primary-600` `#2563EB` |
| 人才分类·核心 | 核心人才 | `success` `#16A34A` |
| 人才分类·胜任 | 一般胜任 | `neutral-600` `#4B5563` |
| 人才分类·问题员工 | 待改进 | `danger` `#DC2626` |
| 关键岗位标记 | 关键岗位 | `warning` `#F59E0B` 标签 |

### 3.5 数据可视化色板（图表系列色，按顺序取用）

```
#2563EB  #16A34A  #F59E0B  #DC2626  #0EA5E9  #8B5CF6  #14B8A6  #EC4899
```

> 九宫格九格用主色到浅色的渐变色阶（左下浅→右上深主色），高潜区用 `primary-600`，待改进区用 `neutral-200`。

## 4. 字体规范

| 用途 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面主标题 H1 | 20px | 600 | 28px |
| 区块标题 H2 | 16px | 600 | 24px |
| 小标题 H3 | 14px | 600 | 22px |
| 正文/表格 | 14px | 400 | 22px |
| 辅助/面包屑/说明 | 13px | 400 | 20px |
| 标签/角标 | 12px | 400 | 18px |
| 数字（看板大数） | 28–36px | 600 | — |

字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。数字建议用等宽数字特性（`font-variant-numeric: tabular-nums`）便于对齐。

## 5. 间距 / 圆角 / 阴影

### 5.1 间距（8px 基准栅格）

| Token | 值 | 用途 |
| --- | --- | --- |
| `space-xs` | 4px | 标签内边距、紧凑间隙 |
| `space-sm` | 8px | 元素间小间距 |
| `space-md` | 16px | 卡片内边距、表单行距 |
| `space-lg` | 24px | 内容区留白、区块间距 |
| `space-xl` | 32px | 大区块分隔 |

### 5.2 圆角

| Token | 值 | 用途 |
| --- | --- | --- |
| `radius-sm` | 4px | 按钮、输入框、标签 |
| `radius-md` | 8px | 卡片、弹窗 |
| `radius-full` | 999px | 头像、圆形角标 |

### 5.3 阴影

| Token | 值 | 用途 |
| --- | --- | --- |
| `shadow-sm` | `0 1px 2px rgba(0,0,0,.05)` | 卡片 |
| `shadow-md` | `0 4px 12px rgba(0,0,0,.08)` | 弹窗、下拉 |
| 表格 | 无阴影，用 `neutral-200` 边框 | |

## 6. 组件视觉规范

### 6.1 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | `primary-600` 实底 + 白字，hover `primary-700` |
| 次按钮 | 白底 + `neutral-200` 边框 + `neutral-900` 字 |
| 文字按钮 | 无底无框，`primary-600` 字（用于表格操作列） |
| 危险按钮 | `danger` 字或实底（删除类） |
| 尺寸 | 默认高 32px，大 40px，小 24px；圆角 `radius-sm` |

> 表格操作列统一用「文字按钮」：编辑（主色）/ 删除（danger）/ 结束（neutral）。

### 6.2 表格（B 端核心组件）

| 项 | 规范 |
| --- | --- |
| 表头 | `neutral-100` 底，`neutral-600` 字，14px/600 |
| 行高 | 48px，单元格上下内边距 12px |
| 斑马纹 | 可选；hover 行变 `neutral-50` |
| 边框 | 横向分隔线 `neutral-200`，无竖线 |
| 操作列 | 固定右侧，文字按钮，按状态显隐（见状态机） |
| 空态 | 居中插画 + 灰字提示 + 主操作按钮 |

### 6.3 状态标签 Tag（业务对象状态）★

统一为圆角小标签（`radius-sm`，12px 字，左侧小圆点）：

| 状态 | 圆点色 | 文字/底 |
| --- | --- | --- |
| 未开始 / draft | `neutral-400` | 灰字浅灰底 |
| 进行中 / running | `warning` | 橙字浅橙底 |
| 已生成 / 已完成 / done | `success` | 绿字浅绿底 |
| 已结束 / archived | `neutral-600` | 深灰字浅灰底 |

### 6.4 表单

| 项 | 规范 |
| --- | --- |
| 标签 | 左对齐或顶对齐，14px `neutral-600`，必填前置红星 |
| 输入框 | 高 32px，`neutral-200` 边框，focus 主色边框 + `primary-50` 外发光 |
| 「AI 建议」态 | 字段旁显示 AI 建议值 + "采用"链接（呼应给建议不给结论） |
| 默认值态 | 系统默认值以浅灰预填，可编辑 |

### 6.5 弹窗 / 抽屉

| 项 | 规范 |
| --- | --- |
| 弹窗 | 居中，`radius-md`，`shadow-md`，标题 16px/600 |
| 抽屉 | 右侧滑出，宽 480–720px（复杂表单用抽屉） |
| 选择器弹窗 | 引用型字段（如标准引用指标）用此，不在当前页新建原子 |

### 6.6 卡片 / 看板组件

| 项 | 规范 |
| --- | --- |
| 卡片 | 白底，`radius-md`，`shadow-sm`，内边距 `space-md` |
| 数据卡（KPI） | 大数字 + 标签 + 同环比，看板顶部排布 |
| 图表卡 | 标题 + 图表区 + 图例，配色用 §3.5 |

## 7. 页面级布局模板

### 7.0 操作按钮位置统一规则（全局强约束）★

所有页面的操作按钮位置必须一致，避免各页各摆：

| 页面类型 | 主操作 | 行/项操作 | 说明 |
| --- | --- | --- | --- |
| 列表页 | **筛选区下方、列表上方的左上角** | 表格**最右列**（文字按钮） | 主操作如"新建"，不放页面标题右侧 |
| 详情/编辑页 | **顶部工具条右侧** | — | 如 保存/发布/撤回 |
| 向导页 | **底部固定栏** | — | 上一步/下一步/完成 |
| 弹窗/抽屉 | 底部右侧 | — | 取消(左)/确定(右) |

> 冲突时以本规则为准；各功能文件的按钮位置须对齐此表。

### 7.1 列表页（最高频）

```
[面包屑]
[页面标题]
[筛选区：名称输入 + 类型/状态下拉 + 查询/重置]
[主操作(左上)：新增/创建]              [次操作：导入/词典]
[表格：业务列… | 状态(Tag) | 创建时间 | 负责人 | 操作(最右列·文字按钮)]
[分页：共 N 条 · 每页 N 条 · 页码 · 前往 N 页]
```

> 主操作在筛选区下方、列表左上角；行操作在表格最右列。项目/任务类列表必含「状态」列(Tag)+「负责人」+「创建时间」。

### 7.2 配置/详情页

```
[顶部：← 返回 | 标题 + 状态Tag |            操作(右侧)：保存/发布/撤回]
┌─左：锚点菜单/结构树/步骤条─┬─右：内容区────────────┐
│ 岗位信息 / 岗位标准 / 学习方案 │  当前锚点分区的表单     │
│ 或 任职(责-任) / 资格(4D)      │  含 默认值 / AI建议     │
└──────────────────────────┴────────────────────────┘
```

> 详情页操作固定在**顶部右侧**。左侧锚点菜单选中态：蓝底+左侧蓝条。

### 7.3 项目向导页（诊断/测评/盘点）

顶部步骤条（Steps）+ 当前步表单 + 底部「上一步/下一步/运行」：

```
① 建项目 → ② 选范围/对象 → ③ 配数据/规则 → ④ 运行 → ⑤ 结果
```

### 7.4 看板/结果页

```
[筛选/维度切换]
[KPI 数据卡行：4–5 张]
┌─图表卡（左大）──────┬─图表卡（右）──┐
│ 九宫格/拟合/气泡     │ 分布/雷达      │
└────────────────────┴───────────────┘
[明细数据表]
[风险提示 inline warning：如九宫格内生相关]
```

## 8. 图表视觉规范

| 图表 | 用途 | 视觉要点 |
| --- | --- | --- |
| 气泡图 | 关键岗位诊断（经济视角） | X需求×Y供给，红泡/灰泡（§3.4），气泡大小=人数 |
| 九宫格 | 盘点·个人定位 | 3×3 网格，色阶渐变，内生相关 inline 提示 |
| 拟合线 | 盘点·组织规律 | 散点 + 拟合曲线（支持倒U），主色线 |
| 雷达图 | 胜任看板·标准vs实测 | 双层：标准（虚线灰）vs实测（主色实线），达标绿/差距红 |
| 分布图 | 组织看板·人才分布 | 柱状/直方，主色系 |
| 均值-波动图 | 盘点·能力优势短板 | 误差棒，高均值低波动=优势（绿） |

通用：网格线 `neutral-200`，坐标轴字 `neutral-600` 12px，图例置顶或右侧。

## 9. 响应式与无障碍

| 项 | 规范 |
| --- | --- |
| 断点 | ≥1440 宽屏（左导航展开）；1024–1440 常规；<1024 左导航折叠为图标 |
| 主体 | B 端按桌面优先，最小适配 1280 |
| 对比度 | 正文文字与背景对比度 ≥ 4.5:1 |
| 状态不只靠色 | 状态除颜色外加圆点/文字（色盲友好） |
| 焦点态 | 键盘可达元素有可见 focus 环（主色） |
