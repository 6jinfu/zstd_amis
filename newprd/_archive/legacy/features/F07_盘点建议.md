# 功能明细 F07 · 人才盘点（评鉴中心 · 析数）

> 归属：评鉴中心 · 盘点。承接测评（F06，取数）的产出，把测评/绩效/人员数据整合分析，给人员分层。
> 一句话：建一个盘点项目，圈定盘点对象和比对标准，通过"盘点活动"引入各类数据，按分层规则把人落到不同层，结果可校准、可发起培训、可沉淀人才池。
> 依赖：F06 测评（AssessmentResult）、人才标准（比对基准）、关键岗位（可选加权，本期不做）· 下游：发展中心（差距驱动培养）、人才中心（人才池）。
> 设计红线：**数据流转闭环**（每个数据都有明确来源与设置入口，不冒无源功能点）；页面清爽、少提示文案，不堆说明。

---

## 1. 功能定位

- 盘点 = 把一批人的**测评/绩效/人员**数据放在一起比较，按规则**分层**（谁优秀、谁中坚、谁待发展），并驱动后续培养与人才沉淀。
- 形态：**列表型项目**（可多次盘点、平列多个项目），纳入 00 §12A 项目制范式。
- **交互形态（关键决策）**：**轻向导建项目 + 详情页多 Tab 运营**。向导只负责建项目（基本信息 + 选对象 + 选标准）；建成后进入项目详情页，其余全部在 Tab 内持续配置/运营。区别于 F01/F02 的"一次性向导走完"——盘点周期长、需追踪进度、需反复校准，故用 Tab 工作区。
- **本期范围**：分层用**矩阵/象限**（不做 T 值、不做循证式算法）；结果为**分层清单 + 分层矩阵图**（组织规律分析图后期再加）；不做审核流。

## 2. 与上游的衔接（数据来源）

| 输入 | 来源 | 用途 |
| --- | --- | --- |
| 盘点对象（员工） | 平台人员数据 | 盘谁 |
| 比对标准 | 对象所在组的人才标准（标准中心） | 差距的标准值 |
| 测评数据 Assessment | **F06 测评项目的 AssessmentResult**（引用）或盘点活动新建补测 | 分层维度取数 |
| 绩效数据 Performance | 绩效系统 | 分层维度取数 |
| 人员数据 People | 平台人员数据（必备） | 分层维度 + 分组 |

> 测评数据只经**盘点活动**引入（见 §5），不在盘点里另存；盘点持引用。F06 产数、F07 用数，靠"盘点活动"挂接。

## 5. 盘点活动（取数）

### 5.1 五种取数方式

| data_mode | 采集方式 | 数据归属 |
| --- | --- | --- |
| 引用已有测评 reference | 勾选一个已完成的 F06 测评项目/结果 | 归 F06，盘点引用 |
| 测评 assessment | 盘点内新建心理测评任务（动力/潜力） | 归 F06 执行，盘点引用 |
| 考试 exam | 盘点内新建考试任务（专业能力/知识） | 归 F06 执行，盘点引用 |
| 360 survey_360 | 盘点内新建 360 任务（通用能力） | 归 F06 执行，盘点引用 |
| 导入 import | 上传分数表（线下述职/外部数据） | 写入 AssessmentResult |

### 5.2 一活动一维度

每个盘点活动只采集一个维度的数据（如"通用能力"活动用 360，"专业能力"活动用考试）。多维度 = 多活动。规则的轴从这些维度里选。

### 5.3 覆盖度与就绪度

| coverage 字段 | 类型 | 说明 |
| --- | --- | --- |
| required_count | int | 盘点对象总数 |
| covered_count | int | 该活动已覆盖对象数 |
| missing_employees | array | 缺数据员工 |

规则：按 `target_employees ∩ 活动已测对象` 算覆盖；不足 → 活动 status=pending，列 missing_employees（提示补测/导入/留空）；所有已配活动 ready → 项目 readiness_status=ready；仅 ready 可进入 running 出结果。

## 6. 盘点规则（矩阵分层）

### 6.1 分层内核

- 选**两个维度**作 X/Y 轴（来自已就绪活动）→ 各轴按阈值分档 → 交叉成格（如 3×3 九宫格）→ 每人按其两维得分落入某格 → 格 = 分层。
- **轴粒度可选**（axis_grain）：**按维度盘**（用 F06 的 dimension_score）或**按指标盘**（用 indicator_score）。同一盘点可选其一，宫格更灵活。
- 阈值、格命名均**给默认值可编辑**（00 §13）。默认分层命名可用"优秀/中坚/待发展"三档式或九宫格式。
- 不做 T 值、不做循证式算法（本期）。

### 6.2 内生相关警告

选两轴时，若两维度在 `corr_risk_with` 命中（如 绩效×能力），格内以 inline warning 提示"两轴相关性高，分层区分度可能弱"。**仅一行提示，不长篇说明**。轴候选与相关关系由 F06/标准侧的维度元数据提供。

- 【操作】主操作 `[btn]创建盘点项目`（筛选区下方左上）；行：`[btn]进入` `[btn]删除`。

### 7.3 L2 建项目向导（3 步）

顶部 Steps：`① 基本信息 → ② 选对象 → ③ 选标准`。底部固定 `[btn]上一步` `[btn]下一步` `[btn]保存草稿`。

- **①基本信息**：`[field]`项目名✅ / 分类 / 场景 / 负责人✅ / 计划起止 / 目标 / `[field]`到期自动结束（开关）。

- **③选标准**：默认按对象所在组自动带出比对标准，可查看；对象跨多组时列出各组标准。校验：对象为空禁用完成。
- 完成 → 生成项目（draft）→ 进入详情页。

### 7.4 L2 项目详情（8 Tab）

顶部：`← 返回 | 项目名 + 状态`[tag]` |` 右侧 `[btn]开始盘点`（就绪后可点）/ `[btn]结束`。

**① 概览**
- 数据卡：对象数 / 数据就绪度（就绪活动/总活动）/ 已出结果人数 / 各层人数分布。
- 就绪度未满时，卡片旁 `[btn]去盘点活动` 直达补数。无长说明。

**② 盘点人员**
- 【列表】`[col]`姓名 / 账号 / 加入方式 / 盘点进度 / 落位结果`[tag]` / 部门 / 岗位 / 职级 / 操作。
- 操作：`[btn]人员管理`（L3 加/移对象）/ `[btn]导出`；行：`[btn]查看报告` `[btn]发起培训` `[btn]加入人才池`。
- 盘点进度 = 该人在所有活动里的数据覆盖比例。

**③ 盘点活动**
- 【列表】`[col]`活动名 / 采集维度 / 取数方式 / 覆盖度(已覆盖/总) / 状态`[tag]` / 操作。
- 操作：`[btn]新建活动`；行：`[btn]编辑` `[btn]查看缺数据` `[btn]删除`。
- **L3 新建活动弹窗**：`[field]`活动名 / `[field]`采集维度 / `[field]`取数方式（引用已有测评/测评/考试/360/导入）。
  - 选"引用已有测评" → `[field]`选择已完成测评项目（列表来自 F06）。
  - 选"测评/考试/360" → 跳 F06 新建对应任务（origin=from_review），回流后此活动 ready。
  - 选"导入" → 上传分数表（模板下载）。
- 缺数据不阻断，标 pending + missing 列表。

**④ 盘点规则**
- 顶部：`[btn]配置分层规则` → **L3 规则弹窗**。
- 弹窗：`[field]`横轴维度 + `[field]`纵轴维度（下拉只列已就绪活动的维度）→ 实时空矩阵预览；`[field]`各轴阈值（默认值可拖）；`[field]`各格命名（默认可改）。两轴相关时 inline warning 一行。
- 保存后规则区显示当前矩阵规格（X/Y/格命名），可重配。

**⑤ 盘点结果**
- 需 readiness=ready 且规则已配、已"开始盘点"后生成。
- 布局：**分层矩阵图（主）+ 分层人员清单（下）**。
  - 矩阵图：X/Y 轴 = 规则维度，格 = 分层，格内显示人数；点格 → 下方清单筛该格人员。
  - 清单：`[col]`姓名 / 部门 / 岗位 / 落位层 / 操作(`[btn]查看报告`)。
- `[btn]查看报告` → **L3 个人盘点报告**：该人各维度得分 + 差距(gap) + 落位。
- 未配规则/未就绪：结果区空态 + 指向对应 Tab 的 `[btn]`，不报错。

**⑥ 盘点校准**
- 【列表】校准项目：`[col]`校准项目名 / 校准人 / 调整人数 / 创建时间 / 操作。
- 操作：`[btn]新建校准`（建一个校准项目）；行：`[btn]进入` `[btn]删除`。
- 进入校准项目：展示当前分层清单，行 `[btn]调整落位` → **L3 校准弹窗**：`[field]`目标层（before 只读→after）+ `[field]`原因✅ → 保存写 CalibrationItem。
- 校准后结果以最新落位为准；矩阵图/清单同步；原始测评分不变。

**⑦ 行动计划**
- 【列表】盘点对象 + 落位 + `[col]`已发起培训`[tag]` / 已入人才池`[tag]` / 操作。
- 行操作：`[btn]发起培训`（带 gap_data 跳发展中心建培养/IDP）/ `[btn]加入人才池`（写人才中心，选池）。
- 支持批量选人后 `[btn]批量发起培训` / `[btn]批量加入人才池`。

**⑧ 设置**
- `[field]`项目名/分类/场景/周期/自动结束/可见范围（角色行级）。详情操作在顶部右侧保存。

### 7.5 状态机

```
草稿(draft) ──数据就绪+配规则+开始盘点──> 进行中(running) ──生成结果──> 已完成(done) ──归档──> 已归档(archived)
   │                                                              │
   └── 编辑（建项目/加对象/配活动/配规则）                          └── 校准（改落位，不回退状态）
```

> 就绪门槛：所有已配活动 ready 且规则已配，才可"开始盘点"进 running。校准在 done 后进行，不改变项目状态。

### 7.6 空态与异常

| 场景 | 处理 |
| --- | --- |
| 无盘点项目 | 列表空态 + `[btn]创建盘点项目` |
