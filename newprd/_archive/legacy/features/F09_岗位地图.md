# 功能明细 F09 · 岗位地图（发展中心 · 岗位串联）

> 归属：发展中心 · 岗位地图。发展中心当前实际形态的核心：把岗位按序列×职级串成可视化发展通道。
> 一句话：创建序列 → 在"序列 × 职级"网格的节点上挂岗位 → 岗位纵向串成发展通道 → 节点可配学习方案、查看通道。
> 依赖：组织结构（序列/层级，F01）、岗位（F04）、学习方案（05 LearningPlan）· 下游：员工看发展通道/学习路径。
> 设计红线：以"岗位串联"为核心（非盘点差距驱动）；节点状态清晰（未配=选岗位、已配=菜单）；页面遵循 07，少文案。

---

## 1. 功能定位

- 岗位地图 = 把岗位按**序列（横向分类）× 职级（纵向等级）**组织成一张图，节点上挂岗位，岗位纵向串成**发展通道**。
- 与发展中心其余（学习方案/职级地图/IDP/培养项目）的关系：岗位地图是**入口与骨架**，节点可下钻到学习方案；职级地图为并列 tab（另抠）。
- 节点两种状态：
  - **未配岗位**：显示 `+配置`，点击 = **选择岗位**挂上。
  - **已配岗位**：显示岗位名（如"总经理"），点击 = 上下文菜单（§4.3）。

## 2. 结构模型

```
序列（横向 tab：专业-人力 / 运营序列 / 技术序列P / 管理序列M / 销售条线 …）
  └── 职级轴（纵向，自下而上：M1 → M2 → M3 → …，来自职级管理）
        └── 节点(序列×职级) ── 挂 0..N 个岗位
              └── 岗位 ── 纵向串成 岗位发展通道
                    └── 挂 学习方案（可选）
```

## 3. 数据模型

### 3.1 PositionMapSequence 序列（横向分类）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| seq_id | string | 系统 | 主键 |
| name | string | ✅ | 序列名（如"管理序列M""技术序列P"） |
| code | string | — | 序列代码（M/P/D…） |
| order | int | 系统 | 横向排序 |
| status | enum | ✅ | active/disabled |

### 3.2 PositionMapLevel 职级（纵向等级，职级管理维护）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| level_id | string | 系统 | 主键 |
| seq_ref | ref | ✅ | 所属序列 |
| name | string | ✅ | 职级名（M1/M2/M3…） |
| rank | int | ✅ | 等级序（自下而上递增） |

### 3.3 PositionMapNode 节点（序列×职级交叉）★

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| node_id | string | 系统 | 主键 |
| seq_ref | ref | ✅ | 序列 |
| level_ref | ref | ✅ | 职级 |
| position_refs | array | — | 挂载的岗位（0..N，来自 F04 岗位；空=未配） |
| learning_plan_ref | ref | — | 该节点/岗位配的学习方案（05 LearningPlan） |

> 节点是否"已配"由 `position_refs` 是否为空判断。一个节点可挂多个岗位（§4.3 添加岗位）。

### 3.4 PositionDevChannel 岗位发展通道（纵向串联，衍生视图）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| channel_id | string | 主键 |
| seq_ref | ref | 所属序列 |
| ordered_nodes | array | 自下而上的节点序列（同序列跨职级） |
| ordered_positions | array | 通道上串起的岗位（按职级） |

> 通道由同序列节点按职级自下而上串成，是"某岗位往上晋升要经过哪些岗位/职级"的可视化。

## 4. 页面与交互（可直接出页面设计）

> `[btn]`按钮 `[col]`列 `[field]`字段 `[tag]`状态 `→`跳转。层级 L1 主页 / L2 子页 / L3 弹窗。
> 按钮位置遵循 07 §7.0。视觉遵循 07；节点/箭头用主色系。

### 4.1 页面清单

| 层级 | 页面 | 类型 | 路由 |
| --- | --- | --- | --- |
| L1 | 岗位地图（序列tab + 网格） | 看板/结构图 | `/develop/position-map` |
| L2 | 职级管理 | 配置 | `/develop/position-map/levels` |
| L3 | 选择岗位弹窗（未配节点点击） | 弹窗 | — |
| L3 | 节点上下文菜单（已配节点点击） | 菜单 | — |
| L3 | 配置学习方案弹窗 | 弹窗 | — |
| L3 | 查看岗位发展通道抽屉 | 抽屉 | — |
| L3 | 添加序列/序列管理弹窗 | 弹窗 | — |

### 4.2 L1 岗位地图主页

- **二级导航**：`岗位地图`（当前）/ `职级地图`（另抠）。
- **序列 tab 行**：横排序列 tab（专业-人力/运营序列/技术序列P/管理序列M/销售条线…）+ 右侧 `[btn]职级管理`。
  - tab 末尾 `[btn]+添加序列`（→ L3 序列管理）。
- **网格主区**（当前选中序列）：
  - 左列 = 职级轴（自下而上 M1→M2→M3…，底部标签"岗位等级"）。
  - 节点列 = 每职级对应节点：
    - 未配 → 灰底 `+配置` 按钮。
    - 已配 → 主色块显示岗位名（多个岗位并列/堆叠）。
  - 节点间上行箭头表示纵向通道。
  - 右侧虚线框 `[btn]+添加岗位发展通道`（新增一条通道列）。
- 空态（新序列无节点）：提示先在职级管理配职级。

### 4.3 L3 节点交互（两种状态）★

**未配节点点击 → 选择岗位弹窗**
- 岗位选择器（来自 F04 岗位库，按序列/职级过滤建议）→ 选定挂到该节点 → 节点变"已配"。

**已配节点点击 → 上下文菜单（5 项，去掉"新增图谱"）**
| 菜单项 | 动作 |
| --- | --- |
| 查看岗位发展通道 | → L3 通道抽屉：该岗位纵向串起的节点/岗位 |
| 配置学习方案 | → L3 学习方案弹窗：给该岗位挂/编辑 LearningPlan（05） |
| 移除岗位 | 摘掉当前岗位（二次确认）；节点无岗位则回到未配 |
| 添加岗位 | 该节点再挂一个岗位（→ 选择岗位弹窗） |
| 取消 | 关闭菜单 |

### 4.4 L3 配置学习方案弹窗

- 显示该岗位的岗位标准维度 → 逐维度挂"目标×形式"（引用 05 LearningPlan）。
- 已配显示方案摘要 + `[btn]编辑`；未配 `[btn]去配置`。
- 详细结构以 05 LearningPlan 为准，本页只做挂接入口。

### 4.5 L3 查看岗位发展通道抽屉

- 右侧滑出：以该岗位为起点，展示同序列自下而上的节点/岗位链（发展通道）。
- 每节点显示 岗位名 + 是否配学习方案`[tag]`；点节点可跳配置。

### 4.6 L2 职级管理

- 按序列配置职级：`[col]`职级名 / 等级序 / 操作。`[btn]新增职级` `[btn]编辑` `[btn]删除`（自下而上 rank 递增）。
- 详情操作在顶部右侧。

### 4.7 状态机（节点）

```
未配(position_refs 空) ──选择岗位──> 已配(≥1岗位) ──添加岗位──> 已配(多岗位)
        ▲                                  │
        └────────── 移除最后一个岗位 ────────┘
```

> 节点无独立生命周期状态，以是否挂岗位区分。序列/职级用 active/disabled。

### 4.8 空态与异常

| 场景 | 处理 |
| --- | --- |
| 无序列 | 主页引导 `[btn]+添加序列` |
| 序列无职级 | 网格空态，引导去职级管理 |
| 节点未配岗位 | 显示 `+配置` |
| 移除岗位 | 二次确认 |
| 岗位库无可选岗位 | 选择器空态，引导先维护岗位（F04） |

## 5. 与 05 / 其他模块的衔接

| 衔接 | 说明 |
| --- | --- |
| 序列/职级 | 与 F01 组织结构的序列×层级一致（同一套分类） |
| 岗位 | 节点挂载的岗位来自 F04 岗位库 |
| 学习方案 | 节点"配置学习方案"引用 05 LearningPlan |
| 职级地图 | 并列 tab，纵向晋升通道（另抠 F10） |

> 本功能是发展中心"岗位串联"的实际形态；05 框架的 IDP/培养项目等为规划蓝图，本期不动（见 05 顶部范围说明）。

## 6. AI 能力

本期岗位地图**无独立 AI 点**。岗位挂载、通道串联为结构性操作；学习方案的 AI（形式推荐/路径排序）归 05/LearningPlan 侧，不在本文重复。
