# 功能明细 F05 · 词库（能力 / 动力 / 潜力）（标准中心 · 定标）

> 归属：标准中心 · 定标 · 词库。是岗位标准（岗位建模）里能力/动力/潜力选择器的数据源。
> 一句话：一套可复用的标准词条库，按维度分为三个独立词库——能力(可分级)、动力(内置特质)、潜力(内置特质)；岗位建模时从这里选词条挂到岗位标准上。

---

## 1. 功能定位

- 词库 = 标准词条的字典，供岗位标准（F04 岗位建模）引用。词条与岗位解耦，只做原子。
- **词库只描述"标准是什么"，不管"怎么测"**（量表/考试是评鉴中心测评的事，不进词库）。
- 维度**固定三个**：能力 / 动力 / 潜力（不支持自定义维度——因各维度字段不同，自定义维度会没有匹配字段）。
- **每个维度一个独立词库、独立页面、独立字段**（三者字段有差异，不强塞一套）。
- 客户自由度放在**分类**（每个词库内可自建分类）。

## 2. 科学依据（字段设计的理由）

| 概念 | 性质 | 是否分级 | 依据 |
| --- | --- | --- | --- |
| 能力 competency | 可观察、可培养的**行为** | ✅ 分级（低→高，行为锚定） | 能力是可训练行为，有层级 |
| 动力 motivation | 相对稳定的**动机倾向** | ❌ 不分级 | 特质/动机是稳定倾向，程度由测评测出，非预设等级 |
| 潜力 potential | 相对稳定的**人格特质** | ❌ 不分级 | 同上；"高低"是测评环节的测量值，不在词库 |

> 所以：能力词库有"等级+行为表现"，动力/潜力词库没有——它们的高低留给评鉴中心测评时体现。

## 3. 三个词库字段

### 3.1 能力词库

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | ✅ | 如"沟通""问题分析" |
| 分类 | ✅ | 自定义（通用能力/专业能力/领导力…） |
| 描述 | ✅ | 这个能力是什么 |
| 关键行为 | 条件 | **未启用等级时**用（一段行为描述）；启用等级后隐藏 |
| 启用等级 | 开关 | **能力默认开**；默认初始化 5 级，最高 10 级 |
| 等级表 | 条件 | 启用后显示；每行：等级名称 / 行为表现 / 等级描述；可增删、拖拽排序、从低到高 |

- 客户可自建能力词条。
- 交互：`启用等级` 与 `关键行为` **二选一显示**——关时用关键行为，开时用等级表。

### 3.2 动力词库（内置 28 词条，4 分组）

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | ✅ | 内置词表（见 §4.1），可补充自建 |
| 分类 | ✅ | 预置 4 组（见 §4.1），可自定义 |
| 描述 | ✅ | 该动机是什么 |

- **无关键行为、无等级**（特质，不分级）。
- 系统内置 28 词条 + 4 分组，客户主要用（可编辑描述、补充自建）。

### 3.3 潜力词库（内置 60 词条，3 分组）

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 名称 | ✅ | 内置词表（见 §4.2），可补充自建 |
| 分类 | ✅ | 预置 3 组（见 §4.2），可自定义 |
| 描述 | ✅ | 该潜力特质是什么 |

- **无关键行为、无等级**。
- 系统内置 60 词条 + 3 分组。

### 三库字段对比

| 字段 | 能力 | 动力 | 潜力 |
| --- | --- | --- | --- |
| 名称/分类/描述 | ✅ | ✅ | ✅ |
| 关键行为 | ✅(未分级时) | ❌ | ❌ |
| 等级 | ✅(默认开) | ❌ | ❌ |
| 内置词条 | 否(客户建) | 28 | 60 |

## 5. 词库规则

- 词条与岗位解耦，只做原子；被岗位标准引用时可查"被哪些岗位引用"。岗位族引用为未来能力，本期不做。
- 词库只定义标准，不定义测评手段（量表/考试在评鉴中心配）。
- 动力/潜力内置词表开箱即用；客户可编辑描述、补充自建、调整分类。
- 分类可自定义，但**维度固定三个**（能力/动力/潜力）。

## 6. 页面与交互

> `[btn]`按钮 `[col]`列 `[field]`字段 `[tag]`状态。视觉遵循 07，按钮位置遵循 07 §7.0。

### 6.1 页面清单

| 层级 | 页面 | 类型 | 路由 |
| --- | --- | --- | --- |
| L1 | 能力词库 | 列表 | `/standard/lib/competency` |
| L1 | 动力词库 | 列表 | `/standard/lib/motivation` |
| L1 | 潜力词库 | 列表 | `/standard/lib/potential` |
| L2/L3 | 能力词条编辑（含等级表） | 弹窗/页 | — |
| L3 | 动力/潜力词条编辑 | 弹窗 | — |

> 三个词库可作为"词库"下的三个子 Tab 或三个二级菜单，视觉一致。

### 6.2 能力词库列表 + 编辑

- 【筛选】`[field]`名称 + `[field]`分类 + `[btn]查询`。
- 【主操作】`[btn]新建能力`（筛选区下方左上）。
- 【列表】`[col]`名称 / 分类 / 描述 / 是否分级`[tag]` / 等级数 / 被引用数 / 操作(最右列：编辑/删除)。
- **能力词条编辑**：
  - `[field]`名称✅ / `[field]`分类✅(可自建) / `[field]`描述✅。
  - `[field]`关键行为（启用等级后隐藏）。
  - `[field]`启用等级(开关，默认开)。
  - 启用后【等级表】：`[col]`等级名称✅ / 行为表现✅ / 等级描述 / 操作(复制·删除·拖拽)。默认 5 行(可命名如 初级/中级/高级/资深/专家)，最高 10 行。

### 6.3 动力/潜力词库列表 + 编辑

- 【筛选】`[field]`名称 + `[field]`分类(分组) + `[btn]查询`。
- 【主操作】`[btn]新建`（一般用内置，允许补充）。
- 【列表】`[col]`名称 / 分类(分组) / 描述 / 被引用数 / 操作。
- 可按分组折叠展示（动力4组/潜力3组）。
- **词条编辑**：`[field]`名称✅ / `[field]`分类✅ / `[field]`描述✅（无等级、无关键行为）。

### 6.4 空态
- 能力词库无数据：引导 `[btn]新建能力`。
- 动力/潜力：默认已内置，不空。

## 7. 与岗位标准(F04)的衔接

- F04 岗位建模的能力/动力/潜力"选择器"，数据源就是本三个词库。
- 能力选择器：选词条 + 选等级（因能力有等级）。
- 动力/潜力选择器：选词条（无等级）。
- 选完在岗位标准里呈现 名称/(等级)/描述。

## 8. 验收要点

- [ ] 三个独立词库（能力/动力/潜力），维度固定不可自定义。
- [ ] 能力：名称/分类/描述/关键行为 + 可选等级(默认开,5级默认/10级上限,行为表现+等级描述)；关键行为与等级二选一。
- [ ] 动力/潜力：名称/分类/描述，无等级无关键行为。
- [ ] 内置动力 28 条(4组)、潜力 60 条(3组)，开箱即用，可编辑/补充。
- [ ] 分类可自定义；词条可查被引用。
- [ ] 作为 F04 岗位建模选择器的数据源。
- [ ] 按钮位置/视觉遵循 07。
