# 功能明细 F14 · 人才中心设置（系统设置 · 人才中心相关）

> 归属：系统设置 · 人才中心相关配置。为人才中心（F10–F13）提供数据源与规则的维护入口，保证功能闭环。
> 一句话：三项设置——个人画像设置（可见范围+分区显隐）/ 人才池设置（准备度）/ 继任设置（准备度+风险规则+学员端可见）。
> 依赖：人员、角色权限 · 下游：人才列表(F10)、人才池(F11)、继任地图(F12)。
> 设计红线：只做有数据源支撑的设置项；无录入来源的项本期隐藏（见 §5）；仿竞品结构；页面清爽。

---

## 1. 定位

人才中心的若干功能依赖全局规则/口径。本文集中这些配置入口，避免"功能用了某规则却无处维护"。三项：个人画像设置 / 人才池设置 / 继任设置（对齐竞品「设置」分组）。

## 2. 个人画像设置（对应 F10 个人画像）★

仿竞品「个人画像设置」。控制个人画像**谁能看**与**看哪些分区/字段**。

### 2.1 可见范围（三档开关）

| 开关 | 说明 |
| --- | --- |
| 团队管理者可见范围 | 开启后，团队管理者可查看其管辖员工的个人画像 |
| 员工可见范围 | 员工可见自己画像的范围 |
| 管理端可见范围 | 管理端可见范围 |

### 2.2 分区与字段显隐（按画像结构勾选）

| 分组 | 可勾选字段 |
| --- | --- |
| 基本信息 | 姓名(账号)/岗位/部门/性别/年龄/职级/司龄/政治面貌/婚姻状态/学历/兼职部门/兼职岗位/工号/首次参加工作日期/直属经理/人员类型/员工状态/试用期/转正日期/转正状态/身份证号/生日/入职时间/账号有效期 |
| 综合信息 | 标签信息/综合能力/绩效表现/职业特征评估/职责任务 |
| 个人履历 | 内部任职履历/外部工作经历/教育经历/奖惩信息 |
| 人才表现 | 人才测评/人岗匹配/盘点九宫格/继任图谱/人才池 |
| 培训学习 | 总览数据/培训学习/课程学习/参加考试/个人发展计划 |

> 勾选项决定 F10 个人画像详情页各分区/字段的显示；结合角色做字段级权限（00 §16）。底部 `[btn]保存`。

## 3. 人才池设置（对应 F11）★

仿竞品「人才池设置」。本期仅**准备度设置**（有数据源支撑）。

### 3.1 准备度设置

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| readiness_id | string | 主键 |
| name | string | 准备度名称 |

- `[btn]新增准备度`（最多 5 个）；行 `[btn]删除`。
- 供 F11 池成员 / F12 继任者的准备度取值。

## 4. 继任设置（对应 F12）★

仿竞品「继任设置」。三块：继任准备度 / 继任风险规则 / 学员端设置。

### 4.1 继任准备度（多档）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 序号 | int | 排序 |
| name_zh / name_en / name_zh_tw | string | 自定义名称（简/英/繁，≤200） |
| color | color | 颜色设置 |
| remark | text | 备注（≤500） |

- `[btn]添加准备度阶段`（最多 10）；行 `[btn]删除`。

### 4.2 继任风险规则

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 序号 | int | 排序 |
| name_zh / name_en / name_zh_tw | string | 自定义名称（简/英/繁） |
| color | color | 颜色设置 |
| remark | text | 备注 |
| auto_rule | object | 自动判定规则：`继任占比 >= 阈值`（给默认可编辑） |

> 继任风险按"继任占比（现有继任者/目标人数）≥ 阈值"自动判定档位，供 F12 岗位卡风险点/筛选用。

### 4.3 学员端设置

| 开关 | 说明 |
| --- | --- |
| 学员端是否可见 | 开启后，学员端可查看自己继任的岗位/部门及继任准备度 |

## 5. 本期隐藏项（无数据源，暂不做）★

| 隐藏项 | 原属 | 原因 |
| --- | --- | --- |
| 标签库维护 | F10 标签 | 目前没有标签数据录入来源 |
| 自动标签规则 | F10 标签 | 无规则数据来源 |
| 干部/管理者口径 | F13 干部结构 | 暂无干部定义 |
| 年度对比数据 | F13 组织结构/干部结构 | 无历史快照数据源 |

> 上述在对应 features（F10/F13）标注为"暂隐藏·待数据源就绪再开"，不在管理端暴露入口。

## 6. 页面与交互

> 层级 L1 设置页。按钮位置遵循 07 §7.0（详情操作顶部/底部）。

| 层级 | 页面 | 路由 |
| --- | --- | --- |
| L1 | 个人画像设置 | `/settings/persona` |
| L1 | 人才池设置 | `/settings/talent-pool` |
| L1 | 继任设置 | `/settings/succession` |

- 个人画像设置：三开关 + 分组字段勾选 + `[btn]保存`。
- 人才池设置：准备度列表 + `[btn]新增准备度`(≤5)。
- 继任设置：继任准备度表(≤10) + 继任风险规则表(自动判定) + 学员端开关 + `[btn]应用`。
