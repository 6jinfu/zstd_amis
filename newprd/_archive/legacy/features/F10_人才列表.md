# 功能明细 F10 · 人才列表（人才中心 · 人才档案）

> 归属：人才中心 · 人才档案 · 人才列表。人才中心最细粒度的全量台账底座，群组/池/看板都从此派生。
> 一句话：全量人才台账列表（多维筛选+对比+导入）；点进=个人画像详情页，只读聚合标准/测评/盘点/继任/池/培训/IDP 全链数据。
> 依赖：People 人员、标准、测评(F06)、盘点(F07)、发展中心、人才池 · 本模块不产新数据，只读聚合 + 标签。
> 设计红线：一套底层数据多粒度聚合；聚合区只读、点进跳源模块；页面清爽、少文案。

---

## 1. 功能定位

- 人才列表 = 全量人才明细台账，人才中心底座。
- 两个页面：**列表页**（台账 + 筛选 + 对比 + 导入）+ **个人画像详情页**（聚合个人全链数据）。
- 人才中心菜单结构（参考竞品重构，**本期不做人才群组、胜任看板**）：
  ```
  人才档案（人才列表）
  人才池
  继任地图
  组织看板
  设置（人才池设置 / 继任设置 / 个人画像设置）
  ```
- 本文抠"人才列表 + 个人画像"；池/继任地图/看板另抠。

## 2. 数据模型

### 2.1 TalentRecord 人才台账（列表行）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| employee_id | ref | 员工 |
| name / account | string | 姓名 / 账号 |
| gender / age | — | 性别 / 年龄 |
| dept | ref | 部门 |
| position_id | ref | 现岗位 |
| level | string | 职级（P4/M1/L2…） |
| entry_date | date | 入职时间 |
| tenure | decimal | 司龄 |
| status | enum | 启用/禁用 |
| tags | array | 标签（§3） |
| latest_review_cell | string | 最近盘点落位（来自 F07） |
| talent_category | enum | 分类（来自盘点/规则） |

> 台账为只读聚合，字段来自 People + 各上游模块，不在此新增业务数据。

### 2.2 TalentTag 标签（6 类，手动 + 自动）★

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| tag_id | string | 主键 |
| category | enum | 基本 / 身份 / 荣誉 / 风险 / 能力 / 其他 |
| name | string | 标签名 |
| source | enum | `manual 手动` / `auto 系统生成` |
| rule_ref | ref | auto：生成规则（如"连续2年高绩效"来自绩效、"中坚力量"来自盘点落位） |

> 自动标签由规则从上游数据生成（盘点落位/绩效/测评…）；手动标签人工打。个人画像设置里配可用标签与自动规则。

## 3. 标签体系（6 类）

> **本期范围**：标签**维护入口与自动标签规则暂隐藏**（无数据录入来源，见 F14 §5）。画像"标签信息"分区仅展示既有标签数据，管理端不提供标签库维护/自动规则配置；待数据源就绪再开。

| 类 | 示例 | 常见来源 |
| --- | --- | --- |
| 基本标签 | 2024年度新星/985/硕士/90后/兴趣 | 手动 + 人员数据 |
| 身份标签 | 有项目管理经验/10人以上团队管理 | 手动 |
| 荣誉标签 | 高级工程师认证/销冠/优秀员工/中坚力量 | 手动 + 盘点自动 |
| 风险标签 | 三级产研事故/离职风险 | 手动 + 系统 |
| 能力标签 | 分析能力高/问题解决高 | 测评自动 |
| 其他标签 | 连续2年高绩效/效果达成≥80% | 绩效自动 |

## 4. 页面与交互（可直接出页面设计）

> `[btn]`按钮 `[col]`列 `[field]`字段 `[tag]`状态 `→`跳转。层级 L1 列表 / L2 详情 / L3 弹窗。
> 按钮位置遵循 07 §7.0。视觉遵循 07。文案克制。

### 4.1 页面清单

| 层级 | 页面 | 类型 | 路由 |
| --- | --- | --- | --- |
| L1 | 人才列表 | 列表 | `/talent/list` |
| L2 | 个人画像详情 | 详情/聚合 | `/talent/persona/{employeeId}` |
| L2 | 人才对比 | 对比 | `/talent/compare` |
| L3 | 导入人员信息弹窗 | 弹窗 | — |
| L3 | 标签管理弹窗（打/移标签） | 弹窗 | — |

### 4.2 L1 人才列表

- **筛选**：`[field]`部门 / `[field]`岗位 / `[field]`职级 下拉 + `[field]`姓名/账号搜索 + `[field]`标签筛选 + `[btn]查询` `[btn]导出` `[btn]重置筛选`。
- **表控件行**（筛选区下方左上）：`[btn]人才对比 (n/5)` + `[btn]导入人员信息` + 右侧 `[field]`过滤禁用人员（开关）。
- **表**：`[col]`姓名 / 账号 / 部门 / 岗位 / 状态`[tag]` / 入职时间 / 职级 / 操作。
- **行操作**：`[btn]查看`（→个人画像）`[btn]编辑` `[btn]加入对比`。
- 空态：引导导入人员信息。

### 4.3 L2 个人画像详情页 ★

顶部：姓名/岗位/部门 + `[btn]导出PDF`。锚点分区（左锚点菜单，右内容），只读聚合：

| 分区 | 内容 | 数据源 |
| --- | --- | --- |
| 基础信息 | 性别/年龄/职级/司龄/政治面貌/婚姻/学历 | People |
| 标签信息 | 6 类标签 + `[btn]管理标签`(L3) | TalentTag |
| 综合能力 | 绑定能力模型，雷达图/列表切换 | 标准 + 测评 |
| 职业特征评估 | 职业特征 | 测评 |
| 职责任务 | 责-任达成 | 标准 + 绩效 |
| 个人履历 | 内部任职/外部经历/教育/奖惩 | People/履历 |
| 人才测评 | 能力表（名称/标准/自评/综合/总分/查看子指标） | F06 AssessmentResult |
| 人岗匹配 | 当前岗位匹配度 | 标准 vs 测评 |
| 盘点九宫格 | X/Y 轴落位（9 格），支持第三维度 | F07 盘点结果 |
| 继任图谱 | 关键岗位继任 / 组织部门继任 + 准备度 | 继任地图 |
| 人才池 | 入池/出池轨迹（时间） | 人才池 |
| 培训学习 | 统计卡（时长/学分/积分/证书/项目/课程/考试）+ 项目/课程/考试表 | 发展中心/LD |
| 个人发展计划 | 当前 IDP（达标率/周期/辅导人/目标）+ 历史 IDP | 发展中心 IDP |

> 各分区**只读**；点分区内条目跳对应源模块（如点盘点九宫格→F07 盘点结果，点 IDP→发展中心）。暂无数据分区显占位。

### 4.4 L2 人才对比 ★

- 从列表勾选 2–5 人 → `[btn]人才对比` 进入。
- 并排列（每人一列）对比关键画像字段：基础信息 / 能力雷达 / 盘点落位 / 绩效 / 关键标签 / 准备度。
- `[btn]移除` 某人；`[btn]导出`。

### 4.5 L3 导入人员信息

- 上传模板（人员字段）；解析预览 + 校验（重复/缺字段）；确认导入。

### 4.6 状态机

人才台账无独立业务状态（跟随 People 启用/禁用）。标签有 手动/自动 两来源，自动标签随上游数据刷新。

### 4.7 空态与异常

| 场景 | 处理 |
| --- | --- |
| 无人员 | 列表空态 + 导入引导 |
| 画像某分区无数据 | 显占位"暂无数据"，不报错 |
| 对比未选人 | `[btn]人才对比`禁用 |
| 对比超 5 人 | 达上限禁止再加 |
| 导入字段缺失 | 校验提示，不整批失败 |

## 5. 与上游模块的聚合关系（只读）

```
People ──> 基础信息/履历
标准+测评(F06) ──> 综合能力/人才测评/人岗匹配
盘点(F07) ──> 盘点九宫格/talent_category/自动标签(中坚力量…)
绩效 ──> 职责任务/自动标签(连续高绩效…)
继任地图 ──> 继任图谱
人才池 ──> 入池/出池轨迹
发展中心 ──> 培训学习/IDP
```

> 本模块不产新数据；某分区缺数据=上游未跑通，可反向验证数据链。

## 6. AI 能力

本期**无启用的 AI 点**。标签相关 AI（`talent_tag_suggest` 自动标签建议）随标签维护入口一并暂隐藏（见 §3、F14 §5），待标签数据源就绪再开。
