# 功能明细 F08 · 测评工具库（评鉴中心 · 测评配置）

> 归属：评鉴中心 · 测评。为三类测评项目（F06）提供可引用的题目/问卷/量表与成卷。
> 一句话：三个并列的库——**题库（考试用）/ 问卷库（360用）/ 量表库（人才测评用）**；题目/问卷题关联指标，成卷供项目引用；F06 只"选择器引用"，不在项目里造原子。
> 依赖：标准中心·指标库（题目/问卷题关联指标）· 下游：F06 三类测评项目引用。
> 设计红线：库与项目解耦（库产原子、项目引用）；关联指标是打通"测评→盘点按指标/维度出分"的关键锚点；页面遵循 07，列表风格与既有指标库一致。

---

## 1. 功能定位

- 测评工具库 = **测评项目的原料仓库**。F06 三类项目各引用一类库：
  | 库 | 供谁用 | 原子 | 成卷/成品 |
  | --- | --- | --- | --- |
  | **题库** | 考试项目 | 试题（单选/多选/判断/填空/问答…） | 试卷（含默认卷） |
  | **问卷库** | 360评估项目 | 问卷题（关联指标） | 问卷 |
  | **量表库** | 人才测评项目 | 经典量表（后台绑定） | 量表（可直接选用） |
- **关联指标锚点**：题目/问卷题都可关联指标 → 测评结果才能按指标出分、聚合出维度分（对接 F06 §4 双粒度出分、F07 按指标/维度盘）。
- **解耦**：库在此维护，F06 项目用"选择器弹窗"引用（07 §6.5），不在项目内新建题目/问卷/量表。

## 2. 库的组织形态

```
评鉴中心 · 测评 · 工具库
├── 题库    （试题管理 + 试卷/组卷）
├── 问卷库  （问卷题 + 问卷）
└── 量表库  （经典量表，后台绑定）
```

三库并列，各自左侧类别树 + 右侧列表（视觉与标准中心·指标库列表一致：左类别树 + 筛选 + 表格 + 分页）。

# 第一部分 · 题库（考试用）

## 3. 题库数据模型

### 3.1 ExamQuestion 试题（原子，按截图·新增试题弹窗）★

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| question_id | string | 系统 | 主键 |
| type | enum | ✅ | 题型：单选/多选/判断/填空/问答 |
| bank_ref | ref | ✅ | 所属题库（类别） |
| difficulty | enum | ✅ | 难度：易/中等/难 |
| score | decimal | ✅ | 分数 |
| knowledge_points | array | — | 知识点（回车确定多个） |
| indicator_ref | ref | — | **关联指标**（下拉选指标库指标；出分聚合锚点） |
| expiry_date | date | ✅ | 过期日期 |
| language | enum | ✅ | 中文/英文 |
| is_private | bool | ✅ | 是否私有（私有仅创建人用；非私有授权可用） |
| stem | text | ✅ | 题干内容（≤3000，支持高级编辑器） |
| options | array | 条件 | 选项（选择题）|
| answer | object | ✅ | 正确答案（判分依据） |
| attachment | ref | — | 附件（≤500M，视频仅 mp4） |
| creator | ref | 系统 | 出题人 |
| status | enum | ✅ | active/disabled |

### 3.2 ExamPaper 试卷（成卷，供考试项目引用）★

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| paper_id | string | 系统 | 主键 |
| name | string | ✅ | 试卷名 |
| is_default | bool | — | 是否默认试卷（供 F06 考试直接选，免逐题挑） |
| compose_mode | enum | ✅ | `manual 手动选题` / `random 随机组卷（按题型/难度/指标抽题）` |
| question_refs | array | 条件 | manual：选定题目 |
| random_rule | object | 条件 | random：抽题规则（题型×难度×数量×指标范围） |
| total_score | decimal | 系统 | 总分（题目分汇总） |
| indicator_coverage | object | 系统 | 覆盖指标（供 F06 按指标出分映射） |
| status | enum | ✅ | active/disabled |

> 默认试卷解决 F06 "考试用默认试卷、不逐题挑"的诉求。

## 4. 题库页面（按截图·试题管理）

### 4.1 L1 试题管理列表
- 左：`题库类别`树（+ `[btn]设置` + 关键字搜索）。
- 筛选：`[field]`题干 / `[field]`知识点 / `[field]`题型 + `[btn]筛选/重置`。
- 操作（筛选区下方左上）：`[btn]新增` / `[btn]AI智能出题` / `[btn]导入试题` / `[btn]导出`；勾选后 `[btn]编辑/复制/移动/放入回收站`。
- 【表】`[col]`题型 / 题干 / 难度 / 分数 / 出题人 / 操作(`[btn]编辑`)。
- 分页 + 回收站 tab。

### 4.2 L3 新增/编辑试题弹窗（按截图）
- **基本信息**：题型✅ / 所属题库✅ / 难度✅ / 分数✅ / 知识点 / **关联指标**（下拉选指标库）/ 过期日期✅ / 语言 / 是否私有✅。
- **试题内容**：题干✅（高级编辑器）/ 上传附件。
- 底部：取消 / 确定。

### 4.3 L2 试卷/组卷页
- 试卷列表：`[col]`试卷名 / 组卷方式 / 题数 / 总分 / 默认`[tag]` / 状态 / 操作。
- 新建试卷：`[field]`名称 + `[field]`组卷方式（手动选题 / 随机组卷规则）+ `[field]`是否默认。

# 第三部分 · 量表库（人才测评用）

## 7. 量表数据模型

### 7.1 Scale 量表（后台绑定经典量表）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| scale_id | string | 系统 | 主键 |
| name | string | ✅ | 量表名（大五/沙因/贝尔宾/盖洛普/DISC/霍兰德/双因素/WVI/驱动力…） |
| dimension | enum | ✅ | 归属：动力 / 潜力 |
| item_count | int | 系统 | 题本数量 |
| answer_form | enum | 系统 | 答题形态（迫选/排序/李克特）——**后台绑定定死，不在管理端/项目暴露** |
| indicator_map | object | 系统 | 量表结果↔指标/维度映射（出分锚点） |
| ext_provider | string | — | 外部量表提供方 |
| status | enum | ✅ | active/disabled |

> 量表内容与答题形态由后台绑定经典量表，管理端只做启用/停用与选用，不编辑题目、不暴露迫选/排序/李克特。

## 8. 量表库页面（参考指标库列表样式）★

### 8.1 L1 量表列表
- 左：量表类别树（动力 / 潜力 / 定制…，`[btn]设置`）。
- 筛选：`[field]`量表名称 / `[field]`状态 / `[field]`题本数量 + `[btn]查询/重置`。
- 操作：`[btn]新增`（绑定/定制）；勾选 `[btn]批量删除`。
- 【表】`[col]`量表名称 / 题本数量 / 归属维度 / 状态`[tag]` / 操作(`[btn]编辑` `[btn]停用` `[btn]删除`)。
- 分页。

> 视觉与标准中心·指标库列表一致（左类别树 + 筛选 + 表格 + 分页）；内容是量表，非标准指标。

## 9. 与 F06 的引用关系

| 库 | F06 引用点 | 引用方式 |
| --- | --- | --- |
| 题库·试卷 | 考试项目 `paper_ref` | 试卷选择器（含默认卷） |
| 问卷库·问卷 | 360项目 `questionnaire_ref` | 问卷选择器 |
| 量表库·量表 | 人才测评 `scale_refs` | 量表选择器 |

> 引用只读取库原子，不修改；库的"关联指标"随引用带入 F06，驱动结果按指标/维度出分。

## 10. AI 能力

题库保留一处（建议态）：**AI 智能出题** `exam_gen_question`——按知识点/指标/难度生成候选试题，人工审核采纳后入库。不自动发布。

## 11. 验收要点

- [ ] 三库并列（题库/问卷库/量表库），左类别树 + 筛选 + 表格，视觉与指标库一致。
- [ ] 试题字段按截图：题型/题库/难度/分数/知识点/**关联指标**/过期/语言/是否私有/题干/附件。
- [ ] 题库支持 AI 智能出题 / 导入 / 导出 / 回收站；组卷支持手动+随机；含默认试卷。
- [ ] 问卷列表参考产品库样式，**操作栏去掉"下发"**；问卷题有**关联指标**字段（点击选指标）。
- [ ] 量表库列表参考指标库样式；量表后台绑定；**答题形态不暴露**。
- [ ] 题目/问卷题关联指标 → 驱动 F06 按指标/维度出分（对接 F06 §4、F07 轴粒度）。
- [ ] 库与项目解耦：F06 用选择器引用，不在项目内造原子。
