# 功能明细 F13 · 组织看板（人才中心）

> 归属：人才中心 · 组织看板（组织画像）。老板视角——从个人跃迁到组织，揭示组织人才规律。
> 一句话：选部门看该组织的结构/干部/质量/胜任/继任储备/盘点九宫格，全只读聚合，讲"组织故事"。
> 依赖：People、盘点(F07)、测评(F06)、继任(F12)、岗位人效 · 本模块不产新数据，只读聚合。
> 设计红线：完全仿竞品结构；一切按部门筛选；个体脱敏、聚焦规律；页面清爽、图表主色系、少文案。

---

## 1. 功能定位

- 组织看板 = 组织级聚合看板，主用户老板/高管，看组织人才分布与规律。
- **顶部部门选择器**：切部门 → 全看板数据随之刷新（默认全组织）。
- 六大区块：组织结构 / 干部结构 / 干部质量 / 岗位胜任 / 继任储备 / 组织盘点。

## 2. 看板区块（六区）

> **本期隐藏项（无数据源，见 F14 §5）**：①**年度对比**（2025 vs 2026 司龄/年龄/性别比）——无历史快照数据源，本期只显当前值，不做年度对比；②**干部/管理者口径**——暂无干部定义，"干部结构""干部质量"两区块暂隐藏，待口径就绪再开。以下保留完整区块描述，隐藏项已标注。

### 2.1 组织结构（人才结构）

| 维度 | 展示 |
| --- | --- |
| 职级 | 各职级人数分布 |
| 司龄 | 分布 + **年度对比**（2025 vs 2026 平均司龄） |
| 岗位 | 各岗位人数分布 |
| 部门 | 各部门人数分布 |

### 2.2 干部结构

- KPI：整体干部数量(占比) / 管理者平均年龄 / 管理者平均司龄。
- 分布：干部人数分布 / 序列人数分布 / 学历 / 年龄(年度对比) / 司龄(年度对比) / 性别(男女比·年度对比)。

### 2.3 干部质量

- 整体队伍水平 / 序列人才质量。

### 2.4 岗位胜任

- 岗位胜任度分布（实测 vs 标准，来自 gap_data）。

### 2.5 继任储备

- 人才继任表现（**按岗位**）：继任风险 低/中/高 + 目标值 + 标杆人员详情。数据来自 F12。

### 2.6 组织盘点（九宫格）★

- **九宫格**：X 轴（其他维度）× Y 轴（潜力），可选**第三维度**。
- 9 格各显：人数 / 占比 / 人员清单（暂无显"暂无人员"）。
- 九格命名沿用盘点：超级明星①/绩效之星②/潜力明星③/中坚力量④/熟练员工⑤/基本胜任⑥/待发展者⑦/差距员工⑧/问题员工⑨。数据来自 F07 盘点结果。

## 3. 数据模型（聚合视图，非新表）

> 组织看板不产新数据，均为按部门聚合上游。定义聚合查询参数即可。

### 3.1 OrgDashboardQuery 看板查询

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| dept_scope | ref | 部门范围（默认全组织） |
| year_compare | array | 年度对比区间（如 2025 vs 2026） |
| grid_axis | object | 组织盘点九宫格 X/Y/第三维度选择 |

### 3.2 聚合来源

| 区块 | 来源 |
| --- | --- |
| 组织结构/干部结构 | People 人员数据 |
| 干部质量 | 测评(F06) + 盘点(F07) |
| 岗位胜任 | gap_data（标准 vs 实测） |
| 继任储备 | 继任地图(F12) |
| 组织盘点九宫格 | 盘点结果(F07) |

## 4. 页面与交互（可直接出页面设计）

> `[btn]`按钮 `[field]`字段 `[tag]`状态。层级 L1 看板。视觉遵循 07，图表配色 §3.5/§8。文案克制。

### 4.1 页面清单

| 层级 | 页面 | 类型 | 路由 |
| --- | --- | --- | --- |
| L1 | 组织看板 | 看板 | `/talent/org-dashboard` |
| L3 | 九宫格格内人员清单弹窗 | 弹窗 | — |

### 4.2 L1 组织看板

- **顶部**：`[field]`部门选择器（切部门刷新全看板）+ `[field]`年度对比选择。
- **区块布局**（自上而下，卡片分区）：
  1. 组织结构：职级/司龄(年对比)/岗位/部门 图表组。
  2. 干部结构：KPI 卡行 + 分布图表组（干部/序列/学历/年龄/司龄/性别）。
  3. 干部质量：整体队伍水平 + 序列人才质量。
  4. 岗位胜任：胜任度分布图。
  5. 继任储备：按岗位继任表现（风险低/中/高 + 目标值 + 标杆人员详情）。
  6. 组织盘点：九宫格（X×Y + 第三维度），点格 → L3 格内人员清单。
- 图表配色用 §3.5 色板；九宫格用色阶（§3.5 说明）。
- 空态：某区块无数据显"暂无数据"占位，不报错。

### 4.3 权限

- 全组织只读；个体数据脱敏，聚焦规律（00 §16 字段级：潜力等敏感维度可隐藏）。

### 4.4 空态与异常

| 场景 | 处理 |
| --- | --- |
| 部门无数据 | 各区块占位"暂无数据" |
| 盘点未跑 | 组织盘点九宫格空态，指向盘点 |
| 继任未配 | 继任储备空态，指向继任地图 |
| 年度对比缺一年 | 显单年，标注缺失 |

## 5. AI 能力
