# 功能明细 F11 · 人才池（人才中心）

> 归属：人才中心 · 人才池。盘点沉淀的精选人才库（关键人才/继任/梯队/储备），承载"入池→培养→考核→出池"闭环。
> 一句话：卡片式人才池列表（名称/人数/饱和度）；进池详情四 Tab——人员管理 / 培养发展 / 评估考核 / 出池记录，覆盖人才池全生命周期。
> 依赖：盘点(F07)、人才列表(F10)、发展中心培养项目、测评(F06) · 下游：继任地图、组织看板。
> 设计红线：全面复刻竞品结构；四步生命周期清晰；页面清爽、少文案。

---

## 1. 功能定位

- 人才池 = 从全量人才中**精选**出的库（关键岗位/HiPo/继任/梯队/储备），围绕四步闭环运营：
  ```
  ① 人才入池   盘点、人才库检索、线下导入多渠道筛选入池
  ② 培养发展   直接创建/关联培养项目，系统化培养
  ③ 考核评估   定期评估，邀业务领导共评，形成共识
  ④ 合格出池   按项目完成度 + 评估结果综合判定是否合格出池
  ```
- 与人才群组区别：**群组本期取消**（见导航调整）；人才池是盘点产出的精选运营库，非任意分群。

### 3.2 L1 人才池列表

- **顶部流程引导条**：四步（人才入池→培养发展→考核评估→合格出池），每步一句说明。
- **工具条**：`[btn]创建人才池`（主，左上）+ `[btn]导出数据` + 右侧 `[field]`分类筛选 + `[field]`按名称搜索 + `[field]`排序（创建日期近→远）。
- **卡片网格**：每卡 = 池名 / 创建日期 / 现有人数 / 期望人数 / **饱和度环**（现有÷期望，可 >100%）+ `[btn]编辑` `[btn]删除`。

### 3.3 L3 创建/编辑人才池弹窗

- `[field]`名称✅（≤50）/ `[field]`分类 / `[field]`期望人数 / `[field]`管理者✅ / `[field]`备注（≤500）。底部 取消/确定。

### 3.4 L2 人才池详情

顶部：`← 返回` + 池名 + 创建日期 + 备注 + 右侧大数字`现有人数`。

**4 Tab：**

**① 人员管理**
- 操作：`[btn]添加人员`（→L3：盘点/人才库检索/导入 多渠道）+ `[btn]批量操作` + `[field]`账号状态 / `[field]`准备度 / `[field]`选择部门 + 搜索。

**② 培养发展**
- 操作：`[btn]关联项目`（→L3 关联已有 / 新建培养项目）+ 搜索。
- 【表】`[col]`项目名称 / 开始时间 / 结束时间 / 负责人 / 状态`[tag]` / 操作。

**③ 评估考核**
- 操作：`[btn]新建测评`（→L3 建测评方案，接 F06）+ 搜索。
- 【表】`[col]`测评名称 / 起止时间 / 创建日期 / 安排人 / 安排人数 / 状态`[tag]` / 操作。

**④ 出池记录**
- 操作：`[btn]导出数据` + `[field]`账号状态 + 搜索。
- 【表】`[col]`姓名 / 账号状态 / 部门 / 岗位 / 职级 / 入池时间 / 出池 / 操作。

### 3.5 状态机（成员在池内）

```
入池(active) ──培养/考核──> 待出池评估 ──合格──> 出池(合格且任用)
                                        └─不合格──> 留池继续 / 淘汰出池
```

> 出池写 PoolExitRecord（入池~出池时间 + 结论）；池的现有人数/饱和度随成员变动实时算。

### 3.6 空态与异常

| 场景 | 处理 |
| --- | --- |
| 无人才池 | 列表空态 + 创建引导 |
| 池无成员 | 各 Tab 表空态 |
| 期望人数未设 | 饱和度显 `--`，不报错 |
| 饱和度超 100% | 环允许超满，正常显示 |
| 删除池 | 二次确认 |

## 5. AI 能力

保留一处（建议态，00 §17）：**入池人选建议** `pool_candidate_suggest`——按盘点落位/关键岗位缺口给候选入池人选建议，人工确认后入池。不自动入池。
