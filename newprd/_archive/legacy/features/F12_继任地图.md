# 功能明细 F12 · 继任地图（人才中心）

> 归属：人才中心 · 继任地图。围绕关键岗位/组织部门，管理继任者梯队与准备度，可视化继任图谱。
> 一句话：两 tab（关键岗位继任 / 组织部门继任）；岗位卡片图谱看在职与继任者厚薄，点详情进继任者列表管理候选与准备度。
> 依赖：关键岗位(F02/F04 is_key)、盘点(F07)、人才池(F11)、人才列表(F10) · 下游：组织看板（继任储备）。
> 设计红线：全面复刻竞品结构；继任者=候选梯队，带准备度与继任状态；页面清爽、少文案。

---

## 1. 功能定位

- 继任地图 = 关键岗位/部门的**继任梯队管理 + 可视化**：谁在职、有几个继任者、准备度如何、继任风险高不高。
- 两 tab：
  - **关键岗位继任**：以关键岗位为节点，管理各岗位的继任者。
  - **组织部门继任**：以组织部门为节点（同构，另一维度）。
- 继任者来源：人才池(F11)/人才列表(F10)/盘点候选。

## 2. 数据模型

### 2.1 SuccessionPosition 继任岗位（关键岗位继任节点）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| succ_id | string | 系统 | 主键 |
| position_ref | ref | ✅ | 关键岗位（来自 F04 is_key） |
| parent_position_ref | ref | — | 上级岗位（图谱层级） |
| benchmark | ref | — | 岗位标杆（对标标准/人） |
| incumbents | array | 系统 | 在职人员 |
| target_successor_count | int | ✅ | 继任目标人数 |
| current_successor_count | int | 系统 | 现有继任者数 |
| succession_risk | enum | 系统 | 继任风险（高/中/低，按现有vs目标+准备度算） |

### 2.2 Successor 继任者

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| succ_id | ref | 所属继任岗位 |
| employee_id | ref | 继任者 |
| dept / current_position | — | 部门 / 当前岗位 |
| readiness | enum | 准备度（高/中/低准备度；空=未评） |
| succession_status | enum | 继任状态（进行中/已退出） |
| account_status | enum | 账号状态（启用/禁用） |

### 2.3 ReadinessRule 准备度规则

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| rule_id | string | 主键 |
| levels | array | 准备度档（高/中/低 + 判定条件，给默认可编辑） |

### 3.2 L1 继任地图主页

- **两 tab**：`关键岗位继任`（默认）/ `组织部门继任`。
- **工具条**：`[btn]添加关键岗位`（主，左上）+ `[btn]导出` + `[field]`继任岗位 / `[field]`继任者 / `[field]`继任风险 筛选 + `[btn]重置`。
- **统计条**：当前岗位显示数量：N · 当前岗位继任者总数：M。
- **图谱区**（点阵网格背景）：
  - **岗位卡片**（可分层，父子连线）：岗位名 + `[tag]`继任风险点(红/绿/灰) + `在职:N`(头像) + `继任者 X/Y`(现有/目标) + `[btn]详情`。
  - 卡下连线标下级数 `(N)`；无在职显"暂无在职人员"。
  - 右下浮动控件：定位/缩放(100%/±)/全屏/刷新/设置。
- 空态：引导 `[btn]添加关键岗位`。

### 3.3 L3 添加关键岗位弹窗

- `[btn]选择关键岗位`（来自 F04 is_key 岗位）→ 表：`[col]`关键岗位 / 岗位 / 上级岗位 / 岗位标杆 / 继任目标人数 / 继任风险 / 操作。
- 配置目标人数、上级岗位、标杆后加入图谱。

### 3.4 L3 继任者列表弹窗（点"详情"进入）★

- 操作：`[btn]添加继任者` + `[btn]准备度规则` + `[btn]批量操作` + `[field]`继任准备度 / `[field]`继任状态 筛选。
- 【表】`[col]`姓名 / 部门 / 当前岗位 / 准备度`[tag]`(高/中/低) / 继任状态`[tag]`(进行中/已退出) / 状态`[tag]` / 操作。
- 行操作：`[btn]退出` `[btn]调整准备度` `[btn]移除`（已退出者仅 `[btn]移除`）。

### 3.5 L3 添加继任者 / 准备度规则

- 添加继任者：从人才池/人才列表/盘点候选选人 → 加入该岗位继任梯队。
- 准备度规则：配准备度档与判定条件（默认可编辑）。

### 3.6 状态机（继任者）

```
加入(进行中) ──退出──> 已退出 ──移除──> 移出梯队
     │调整准备度（高/中/低）
```

> 继任风险按 现有vs目标继任人数 + 准备度分布 综合算（给默认规则）；现有继任者数随梯队变动实时算。

### 3.7 空态与异常

| 场景 | 处理 |
| --- | --- |
| 无继任岗位 | 图谱空态 + 添加引导 |
| 岗位无继任者 | 卡显"继任者 0"，详情表空态 |
| 无在职人员 | 卡显"暂无在职人员" |
| 现有<目标 | 继任风险偏高（红点提示） |
| 移除继任者 | 二次确认 |

## 4. 与上游/下游的衔接

| 衔接 | 说明 |
| --- | --- |
| 关键岗位 | 来自 F04 is_key（诊断 F02 收口） |

| 准备度 | 结合盘点落位/测评综合评 |
| 下游 | 组织看板·关键岗位储备 |

## 5. AI 能力

保留一处（建议态，00 §17）：**继任者推荐** `successor_suggest`——按岗位标杆/盘点落位/池成员给候选继任者建议 + 准备度初判，人工确认后加入梯队。不自动加入。
