# 功能明细 F01 · 组织结构分析（标准中心 · 定对象）

> 归属：标准中心 · 定对象 · 组织结构。逐功能抠细的产物，最终回填标准中心 PRD。
> 一句话：读取平台已有的部门/岗位/人数数据，用 AI 按所选分析方法推断"序列×层级"，把岗位归到一个个岗位族(组)，形成组织结构矩阵。

---

## 1. 功能定位

- 组织结构 = **序列(横向分工) × 层级(纵向分权)** 的矩阵；矩阵的每个格子 = 一个**岗位族(组 Group)**，格内含若干具体岗位。
- **坐标定义（强约束，不可摆错）**：
  - **横轴 = 岗位序列**（横向分工，如 研发/销售/职能），从左到右并列。
  - **纵轴 = 岗位层级**（纵向分权），**从下到上依次提高**：底部=最低层级(如员工级)，顶部=最高层级(如高管级)。
  - 即矩阵渲染：**列 = 序列，行 = 层级**；行从下往上层级递增。
- 岗位族(组) = 序列×层级交叉。本期仅用于组织结构展示、岗位归类和诊断聚合，不承载独立的标准/测评/培养功能；相关能力作为未来扩展预留。
- 本功能用 **AI 辅助** 完成从"平台已有岗位数据"到"岗位族矩阵"的归类；给建议不给结论，人工可校准。
- **形态 = 基准配置 + 版本管理**（不是普通项目列表）：组织结构是相对稳定的地基，任一时刻有唯一"当前生效版本"；每次重新分析生成新版本草稿，确认后替换生效版，旧版本存档可追溯。纳入 00 §12A 统一项目制范式（第 5 类项目：组织结构分析项目）。
- **入口即可视化**：进入即看当前生效版本的组织结构矩阵，不是列表页；历史版本从页面唤起查看。

## 2. 数据来源划分（关键前提）

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 部门、岗位、岗位类别、岗位人数 | **平台已有** | 企业培训平台已存储，直接读，无需导入 |
| 序列(sequence) | **AI 分析生成** | 平台无，大模型按分析方法推断 |
| 层级(level) | **AI 分析生成** | 平台无，大模型推断 |
| 各分析法评价字段 | **AI 生成 + 用户补说明材料** | 平台无，方法模型驱动 |

> 因此功能起点是"选组织范围"（从平台数据选），不是"导入岗位"。

## 3. 功能流程（8 步）

```
① 选组织范围     从平台已有数据选（部门/岗位/岗位类别/人数已就绪）
② 补充说明材料   可选：缺料时上传辅助材料（职责说明书/组织文件…）
③ 选分析方法     5 种可多选（多视角循证）
④ 各方法勾选维度 模型可裁剪（维度/指标可勾选）
⑤ 自定义宫格     手动定 序列数 × 层级数（快速上线，先让用户定矩阵规格）
⑥ AI 分析        据 方法+平台数据+材料 → 推断序列/层级 → 岗位归到岗位族 + 给依据
⑦ 人工校准       拖拽/调整 AI 归类结果
⑧ 输出岗位族矩阵 每格=一个组(岗位族)，确认生效后供组织展示与关键岗位诊断；标准仍配置到具体岗位
```

## 4. 五种分析方法（模型明细）

> 每种方法 = 一套可勾选的评价模型 + AI 按模型分析。可单选或多选循证；多选时各方法结论整合。

### 4.1 结构分析法
按组织三组指标诊断岗位的结构位置（核心度×等级×职能）。

| 指标组 | 指标 |
| --- | --- |
| 岗位配置 | 人数 / 岗位数 / 人岗比 / 某岗率 / 空岗率 … |
| 人力资源 | 年龄 / 服务年限 / 学历值 / 绩效 / 薪酬 … |
| 组织形态 | 分工 / 分权 / 分钱 / 发展 … |

输出：诊断岗位在序列×等级的结构位置。

### 4.2 结构设计法
按"纵向分权×横向分工"把组织归入五种形态连续带，据此设计序列×层级框架。

- 连续带：职能型 → 事业型 → 矩阵型 → 项目型 → 网络型。
- 4 维度 8 变量对比（●高 ◐中 ◎低）：

| 维度 | 结构变量 |
| --- | --- |
| 环境 | 稳定性 / 响应性 |
| 管理 | 控制性 / 规范性 |
| 分工 | 专业性 / 协同性 |
| 业务 | 规模性 / 多样性 |

输出：定组织整体形态类型 → 指导矩阵框架设计。

### 4.3 岗位定义法（= 责-任模型）
基于"责-任模型"定义岗位，形成从结果到过程的叙述。

- 结构：责(结果) → %(权重) → 任(过程)；一责多任。
- 关联产出：绩效目标 / 人才标准 / 业务流程 / 经验萃取；也作岗位评价的输入。

输出：岗位定义 → 辅助归序列（按职责性质）。

### 4.4 岗位评价法（模型最完整，24 指标，5 级锚定）★
**职责 + 能力** 两大要素，各 3 维度，每维度 4 指标；每指标 1~5 分行为化锚定。**维度/指标用户可勾选**（结构全集，按需裁剪）。

| 要素 | 维度 | 指标（4×） |
| --- | --- | --- |
| 职责 | 任务 | 任务多样性 / 复杂性 / 挑战性 / 重要性 |
| 职责 | 权力 | 团队管理权 / 计划制定权 / 资源配置权 / 方向决策权 |
| 职责 | 环境 | 环境危险性 / 精密性 / 稳定性 / 保密性 |
| 能力 | 专业 | 专业知识 / 专业技能 / 专业学习 / 资格要求 |
| 能力 | 人际 | 团队合作 / 外部谈判 / 表达分享 / 组织协调 |
| 能力 | 思维 | 创新设计 / 逻辑分析 / 系统规划 / 数据分析 |

- 每指标含：指标描述 + 1/2/3/4/5 分各自的行为锚定文字（内置词典，AI 据此打分）。
- 汇总：指标分 →(加权)→ 维度分 →(加权)→ 要素分 →(加权)→ **岗评总分**。
- 权重随勾选动态归一；用户可调。
- 输出：岗评总分 = 岗位价值/等级依据 → 定层级、辅助归序列。

### 4.5 人效分析法
宏观/中观/微观三层分析人力资源有效性。

| 层次 | 分析 | 回答的问题 |
| --- | --- | --- |
| 宏观 | 经济分析 | 整体人力资源配置是否合理 |
| 中观 | 岗位分析 | 哪些岗位配多了 / 重合了 |
| 微观 | 劳动分析 | 哪些人不忙 / 无存在价值 |

- 核心公式：利润 = 营收 − 成本；人效圆(人 × 钱 × 存量静态/增量动态)。
- 输出：岗位数量配置合理性 → 辅助定岗位族的人数配置。

## 5. AI 分析规格

| 项 | 内容 |
| --- | --- |
| 输入 | 平台数据(部门/岗位/岗位类别/人数) + 用户勾选的方法与维度 + 说明材料 + 自定义宫格规格(序列数×层级数) |
| 处理 | 按所选方法模型给岗位打分/判别；推断每个岗位的 序列 + 层级 |
| 输出 | ①推荐的序列清单 ②推荐的层级清单 ③每个岗位归属的岗位族(组) + 归类依据(evidence) ④多方法时给综合结论 |
| 交互 | 全部为"建议态"，人工确认/调整后才生效（给建议不给结论） |

## 6. 自定义宫格（快速上线）

- 用户可手动设 序列数 × 层级数（如 3×3=9 格），先定矩阵规格再让 AI 往格里归岗位。
- 序列名/层级名可手填或采用 AI 推荐。
- 允许纯手动模式（不跑 AI，用户自己拖岗位进格）——保障快速上线与可控。

## 8. 校准（人工）

- 矩阵视图可**拖拽**岗位在格子间移动（改序列/层级）。
- 调整留痕（谁改/原归类→新归类）。
- 校准后重算受影响的组人数/统计。

### 9.3 L2 分析向导（步骤条 6 步）

顶部 Steps：`① 组织范围 → ② 说明材料 → ③ 分析方法 → ④ 维度配置 → ⑤ 宫格设置 → ⑥ 生成`。底部固定 `[btn]上一步` `[btn]下一步` `[btn]保存草稿`。

**① 组织范围**
- 左：平台部门树（多选 checkbox，级联）。右：范围下岗位列表预览 `[col]`岗位名/类别/人数。
- 顶部汇总条：已选 X 部门 · Y 岗位 · Z 人（平台数据实时）。
- 校验：范围为空禁用下一步。

**② 说明材料（可选）**
- 上传区（拖拽/点选，doc/pdf/xls）。已传列表 `[col]`文件名/大小/解析状态`[tag]`(解析中/成功/失败)/`[btn]删除`。
- AI 解析进度；失败 `[btn]重试`。提示："缺材料也可继续，AI 仅基于平台数据分析"。

**③ 分析方法（可多选）**
- 5 张方法卡勾选：结构分析法/结构设计法/岗位定义法/岗位评价法/人效分析法。
- 每卡：图标 + 名称 + 一句话简介（见 §9.2.1）+ `[btn]查看模型`(侧边抽屉展示维度)。可排序（结论整合优先级）。至少选 1。
- 卡片式呈现，简洁留白，不堆砌。

**④ 维度配置**
- 按方法分 Tab；每 Tab 树形勾选(要素→维度→指标)。
- 岗位评价法 24 指标全展开，行悬浮显示 1~5 级锚定。
- 每维度 `[field]`权重滑块 + 实时"权重和=X%"提示（不阻断）；`[btn]AI建议权重`。

**⑤ 宫格设置**
- `[field]`序列数 × `[field]`层级数 → 实时空矩阵预览（列=序列/横，行=层级/纵，层级自下而上递增）。
- 序列名/层级名：`[field]`手填 或 `[btn]采用AI建议`。
- 模式：`[field]`AI自动归类 / 纯手动（手动跳过AI，直接进预览页拖岗位）。

**⑥ 生成**
- 配置汇总只读。`[btn]开始 AI 分析`→分析页；纯手动→预览页。生成结果为**新版本草稿**。
- **点击"开始 AI 分析"后有过渡动画**：按钮 → loading 态平滑切入分析页，配轻量过渡（如渐显/进度环启动动画），让"AI 正在思考"有仪式感，避免生硬跳转。

### 9.4 L2 AI 分析进行中页

- **过渡/进行中动画**：分阶段进度动画（读取平台数据→按方法打分→推断序列/层级→归类），各阶段有流动/点亮的动效，体现 AI 处理过程，不是静态等待。
- 进度条 + 分阶段文字。
- `[btn]转后台`（主页版本状态显"分析中"）。失败：错误 + `[btn]重试` + `[btn]返回改配置`。
- 部分岗位归不出：不阻断，完成后进"待人工归类"篮。
- 完成 → 平滑过渡进入结果预览页（矩阵渐显）。

### 9.5 L2 分析结果预览页（校准 + 确认生效）

**布局**：顶部工具条 + 矩阵主区 + 右侧详情。此页操作的是**新版本草稿**，确认后才替换生效版。
- 顶部：`[field]`方法视图(单法/综合) + `[btn]保存草稿` + `[btn]确认生效`。
- **矩阵**：**列=序列（横向分工），行=层级（纵向分权，从下到上递增）**；格显示 组名/岗位数/人数。
  - 点格 → L3 格内岗位清单：`[col]`岗位/AI序列/AI层级/`[btn]查看依据`。
  - **拖拽**：岗位卡跨格拖动改归属，实时重算统计。
  - **AI建议 vs 人工调整** 视觉区分：AI=常规色；人工改过=主色描边+"已调整"角标。
- `[btn]查看依据` → L3 归类依据弹窗：各方法打分明细(如岗评总分拆解) + evidence。
- **建议校准**（原冲突裁决）：某岗位多方法结论有差异 → 格内标"建议校准"提示徽标，点开 **L3 建议校准弹窗**。

### 9.5.1 L3 建议校准弹窗

- 标题："建议校准"。提示语："因所选分析法从不同视角循证，以下岗位存在不同结论，建议你确认最终归属。"
- 并列展示各方法对该岗位的结论（序列/层级 + 该法打分/依据）。
- `[field]`用户选定最终归属（或手动改序列/层级）。`[btn]采纳` `[btn]保持AI默认`。
- 语气为建议，非报错。

### 9.6 确认生效

`[btn]确认生效` → 二次确认（"将替换当前生效的组织结构，是否继续？可选存为新版本保留历史"）→ 新版本 `is_current=true`、写 effective_at，旧版本转存档 → 生成/更新 Group（岗位族）→ 提示"已生效，生成 N 个组" + `[btn]去关键岗位诊断`。

### 9.7 状态机

```
草稿(draft) ──开始分析──> 分析中(running) ──完成──> 已完成/待确认(done) ──确认生效──> 已生效(effective)
   │                          │失败↺重试                       │
   └──────可编辑──────────────┘              重新分析生成新版本草稿(旧生效版不受影响，直到新版确认生效)
```

> 生效唯一性：任一时刻仅一个版本 is_current；新版生效时旧版自动转存档。

### 9.8 空态与异常

| 场景 | 处理 |
| --- | --- |
| 从未分析过 | 主页显示引导卡 + `[btn]开始分析` |
| 平台无岗位数据 | 范围页空态，引导先维护岗位 |
| 组织范围选空 | 禁用下一步 + 提示 |
| 材料解析失败 | 该文件标失败 + 重试；不阻断 |
| AI 分析超时/失败 | 错误 + 重试 + 返回改配置 |
| 部分岗位归不出 | 进"待人工归类"篮 |
| 多方法结论差异 | 建议校准弹窗，人工确认 |
| 确认生效 | 二次确认；旧版转存档，可恢复 |

- [ ] 多方法结论差异用"建议校准"弹窗（非报错）；待归类岗位有归类篮。
- [ ] 状态机 草稿→分析中→已完成→已生效；生效唯一、旧版转存档、可恢复。
