## 当前有效规则摘要

### 产品范围

- 左侧一级中心：岗位中心、评鉴中心、发展中心、人才中心、系统设置。
- 当前业务入口：组织结构、关键岗位分析、岗位管理、指标库、360 评估、人才盘点、岗位地图、人才列表、职级管理、功能设置。
- 不建设独立首页、独立 AI 对话、测评工具库、独立测评结果、人才发展考试、职级地图、个人发展计划、独立人才池、继任地图、组织看板，以及人才盘点行动计划和设置；人才池仅作为人才盘点项目内的结果应用。

### 统一命名

- 产品名称：人才发展。
- 一级中心：岗位中心，不使用“标准中心”。
- 页面名称：关键岗位分析，不使用“关键岗位诊断”。
- 指标库类别：能力、动力、潜力。
- 360 列表主操作：新建。

### 业务规则

- 岗位标准、360 评估和学习方案均关联具体岗位。
- 能力指标可复用、分类和分级；动力与潜力为固定内容，仅用于专家人才测评场景。
- 组织结构分析和关键岗位分析由服务端编排 Dify，前端不暴露接口或密钥细节。
- 人才盘点只能使用已结束的考试或 360 项目；同一能力取最高有效分，缺失能力按 0 分。
- 盘点使用能力与绩效两个维度，横纵轴可互换；能力默认按 0%–60%、60%–80%、80%–100% 分为低中高，九个宫格文案可逐格修改。
- 创建后人员、项目数据、绩效数据和规则快照锁定；校准通过任务管理，只调整人员落位并记录操作人与调整前后落位。
- 人才池仅在人才盘点项目内使用，可按盘点维度和维度分层选择本次盘点人员组建。
- 盘点项目的“年度盘点、季度盘点、管理者盘点”是同一类别维度，用于项目管理和列表筛选，不代表组织范围或数据源。

### UI 规则

- 左侧为一级中心导航，顶部为当前中心业务菜单。
- 真正的类别管理统一使用“类别”标题、数量、管理入口、增删改和同步刷新；组织范围、岗位范围、业务维度筛选不套用类别管理。
- 列表保持统一工作区和分页位置；长表格横向滚动，操作列固定在右侧。
- 选中态只保留一个明确的蓝色竖线；页面不展示快照、接口、算法、存储等内部实现说明。

## 后续维护约定

1. 产品范围、业务规则或页面验收变化：先更新 11 号 PRD。
2. 组织结构分析或关键岗位分析的接口、快照、状态变化：同步更新 10 号接口文档。
3. 原型冻结后，回归检查导航、称谓、页面入口和交互，再更新 PRD，不新增平行的“当前版”文件。
4. `_archive/` 下的内容只用于追溯，不得用于推导当前页面或新增功能。
