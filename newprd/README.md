## 当前有效规则摘要

### 产品范围

- 左侧一级中心：岗位中心、评鉴中心、发展中心、人才中心、系统设置。
- 当前业务入口：组织结构、关键岗位分析、岗位管理、指标库、评鉴工具、人才盘点、岗位地图、人才列表、职级管理、功能设置；评鉴工具下设 360评估、人才测评、考试三个二级页签。
- 不建设独立首页、独立 AI 对话、测评工具库、独立测评结果、人才测评和考试的新建/详情下级页面、人才发展考试组卷、职级地图、个人发展计划、独立人才池、继任地图、组织看板，以及人才盘点行动计划和设置；人才池仅作为人才盘点项目内的结果应用。

### 统一命名

- 产品名称：人才发展。
- 一级中心：岗位中心，不使用“标准中心”。
- 页面名称：关键岗位分析，不使用“关键岗位诊断”。
- 指标库类别：能力、动力、潜力。
- 评鉴中心一级业务入口：评鉴工具、人才盘点；不将 360评估与人才盘点并列。
- 评鉴工具二级页签：360评估、人才测评、考试；三类列表统一使用类别树和类别管理。
- 360 列表主操作：新建。
- 人才盘点方法：宫格盘点、人才图谱盘点；不使用“九宫格盘点”作为方法名称。

### 业务规则

- 岗位标准、360 评估和学习方案均关联具体岗位。
- 能力指标可复用、分类和分级；动力与潜力为固定内容，仅用于专家人才测评场景。
- 组织结构分析和关键岗位分析由服务端编排 Dify，前端不暴露接口或密钥细节。
- 人才盘点以“宫格盘点 / 人才图谱盘点”二级页签分别管理项目，两种方法各自拥有类别树、列表和创建入口。
- 宫格盘点只能使用已结束的考试或 360 项目；同一能力取最高有效分，缺失能力按 0 分。
- 宫格盘点使用能力与绩效两个维度，横纵轴可互换；能力默认按 0%–60%、60%–80%、80%–100% 分为低中高，各宫格文案可逐格修改。
- 人才图谱盘点按人员、绩效、能力、动力、潜力五类业务数据配置，具体字段分别来自人才列表、固定绩效模板和指标库有效结果；创建页与宫格盘点保持相同的左侧步骤导航，页面不展示 APP、花名册状态或数据模型术语。
- 人才图谱使用两个盘点维度形成六类规律分析，创建页实时展示“已选维度—维度组合—图谱结果”的联动关系；结果以分布图、群体比较图、相关散点图、拟合曲线和热力图呈现，不提供宫格、盘点校准或人才池。
- 人才图谱及人才分层中的统计图统一使用项目内置的 ECharts Canvas 渲染，不使用手写 SVG 或 CSS 色块模拟图表。
- 人才分层不对人员属性赋予优劣分值，仅标准化并汇总绩效、能力、动力、潜力四类有效评分；综合分按 `15% / 25% / 40% / 20%` 划分 A/B/C/D，页面展示累计漏斗、分布和人员明细。
- 创建后人员、项目数据、绩效数据和规则快照锁定；校准通过任务管理，只调整人员落位并记录操作人与调整前后落位。
- 人才池仅在人才盘点项目内使用，可按盘点维度和维度分层选择本次盘点人员组建。
- 盘点项目的“年度盘点、季度盘点、管理者盘点”是同一类别维度，用于项目管理和列表筛选，不代表组织范围或数据源。

### UI 规则

- 左侧为一级中心导航，顶部为当前中心业务菜单。
- 真正的类别管理统一使用“类别”标题、数量、管理入口、增删改和同步刷新；组织范围、岗位范围、业务维度筛选不套用类别管理。
- 列表保持统一工作区和分页位置；长表格横向滚动，操作列固定在右侧。
- 选中态只保留一个明确的蓝色竖线；页面不展示快照、接口、算法、存储等内部实现说明。
