# 人才发展高保真原型

这是一个静态 HTML 业务原型，覆盖岗位中心、评鉴中心、发展中心、人才中心和系统设置等模块。

## 本地预览

项目不需要安装前端依赖，运行：

```bash
python3 serve.py
```

然后访问 <http://127.0.0.1:8765/>。

## 目录说明

- `app/`：静态 HTML、CSS 与交互脚本。
- `newprd/`：当前生效的产品需求与接口说明。
- `prd/`：历史需求资料，仅用于追溯。
- `deliverables/`：业务流程图及可编辑交付文件。
- `screenshots/`：原型视觉回归截图。
- `scripts/`：交付物辅助脚本。

当前需求入口见 [`newprd/README.md`](newprd/README.md)。
