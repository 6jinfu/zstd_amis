# 线框说明 W05 · 人才中心（页面级字段/组件）

> 对应 PRD 06 + 08。五模块按章森三视角：HR工具(列表/群组/池) / 员工(胜任看板) / 老板(组织看板)。
> 本模块只读+呈现，不产新数据。标注：`[btn]`按钮 `[col]`列 `[field]`字段 `[tag]`状态 `→`跳转。

---

## 1. 人才列表 `/talent/list`

**筛选区**：`[field]`姓名 + `[field]`组 + `[field]`关键岗位 + `[field]`人才分类 + `[field]`绩效 + `[btn]查询` `[btn]重置`。
**主操作**：`[btn]导出` `[btn]存为群组`。
**表格列**：`[col]`姓名 / 性别 / 学历 / 司龄 / 组(序列×层级) / 现岗位 / 关键岗位`[tag]` / 最近T值 / 人才分类`[tag]` / 最近绩效 / 操作(查看)。

### 1.1 个人卡片 `/talent/list/{employeeId}`
聚合只读：基础信息 + 我的标准(任职+资格) + 测评结果 + 差距雷达 + IDP 摘要。
`[btn]看胜任看板` `[btn]看IDP` → 对应页面。

---

## 2. 人才群组 `/talent/groups`

**主操作**：`[btn]新建群组`。
**表格列**：`[col]`群组名 / 类型(动态/静态) / 成员数 / 更新时间 / 操作。

### 2.1 群组编辑 `/talent/groups/{id}`
- `[field]`群组名✅ / `[field]`类型✅(动态条件/静态名单)。
- 动态：条件构建器（组/绩效/T值区间/标签…）+ 实时预览成员数。
- 静态：穿梭框固定名单。
- `[btn]用于测评` `[btn]用于盘点` `[btn]用于培养`（作对象来源）。

---

## 3. 人才池 `/talent/pools`

**主操作**：`[btn]新建池`。
**表格列**：`[col]`池名 / 类型(关键岗位/HiPo/继任) / 成员数 / 操作。

### 3.1 池详情 `/talent/pools/{id}`
- `[field]`池类型 / `[field]`面向目标组(继任池)。
- **成员表**：`[col]`成员 / T值 / 准备度`[tag]`(即用/1-2年/3年+) / 历次盘点轨迹 / 操作。
- 继任池额外：关键岗位覆盖与缺口视图。

---

## 4. 组织看板 `/talent/org-dashboard`（老板视角）

**布局**：维度切换 + KPI 卡 + 图表网格。
- **KPI 卡**：总人数 / HiPo 占比 / 关键岗位覆盖率 / 人才密度。
- **人才分布**：年龄×能力 / 绩效×司龄 拟合曲线（含天花板效应），来源独立变量。
- **组织能力基因**：能力优势/短板、枢纽能力（均值-波动）。
- **梯队厚薄**：序列×层级矩阵热力，各组储备分布。
- **关键岗位储备**：覆盖与缺口。
- **人效视图（增值）**：序列×层级 + 人数/成本/利润。
- 个体数据脱敏，聚焦规律。

---

## 5. 胜任看板 `/talent/competency-dashboard`（员工/领导视角）

**对象选择**：员工本人默认本人；业务领导可切下属。
- **岗位标准区**：任职(责-任) + 资格(4D)要求。
- **实测水平区**：各维度实测值。
- **胜任度/差距**：标准vs实测雷达图（标准=虚线灰，实测=主色实线，达标绿/差距红）+ 达标率。
- **个人发展计划区**：当前 IDP 学习旅程与进度 → 发展中心 IDP。
- **发展方向**：下一步要补的维度。
- 权限：员工仅本人；领导限下属；潜力等敏感字段按配置隐藏。
