# 线框说明 W04 · 发展中心（页面级字段/组件）

> 对应 PRD 05 + 08。五个二级菜单：岗位学习方案 / 岗位地图 / 职级地图 / 个人发展计划 / 培养项目。
> 标注：`[btn]`按钮 `[col]`列 `[field]`字段 `[tag]`状态 `→`跳转。

---

## 1. 岗位学习方案 · 列表 `/develop/plans`

**筛选**：`[field]`组(序列×层级) + `[field]`状态 + `[btn]查询`。
**主操作**：`[btn]新建学习方案`。
**表格列**：`[col]`组 / 方案名 / 维度数 / 形式数 / 状态`[tag]` / 操作。

### 1.1 方案编辑 `/develop/plans/{groupId}`
- 头部：选所属组（标准来源）。
- **目标×形式表**：`[col]`待补维度(来自组标准) / 培养目标 / 形式(可叠加：课程/项目/辅导/练习) / `[btn]接入LD资源`。
- `[btn]加目标` `[btn]保存为模板`。

---

## 2. 岗位地图 · 列表 `/develop/position-maps`

**表格列**：`[col]`岗位/组 / 阶段数 / 状态`[tag]` / 操作。

### 2.1 地图编辑 `/develop/position-maps/{id}`
- `[field]`关联岗位/组。
- **阶段编辑器**：阶段列（入门/胜任/骨干/专家，可增删）+ 每阶段挂目标×形式（引用学习方案）。
- `[field]`可视化隐喻(路径/航线)。
- 预览区：路径图。

---

## 3. 职级地图 · 列表 `/develop/level-maps`

**表格列**：`[col]`序列 / 跃迁数 / 状态`[tag]` / 操作。

### 3.1 跃迁通道编辑 `/develop/level-maps/{sequenceId}`
- `[field]`选序列。
- **跃迁表**：`[col]`from层级 → to层级 / 跃迁所需补的维度(系统算相邻层级标准差) / 培养目标×形式。
- `[btn]AI识别跃迁差`。

---

## 4. 个人发展计划 IDP · 列表 `/develop/idps`

**筛选**：`[field]`员工 + `[field]`组 + `[field]`状态 + `[btn]查询`。
**表格列**：`[col]`员工 / 组 / 来源(盘点项目) / 目标数 / 进度 / 状态`[tag]` / 操作。

### 4.1 IDP 详情 `/develop/idps/{employeeId}`
- 头部：员工信息 + 来源盘点 + 整体进度条。
- **差距→目标区**：`[col]`差距维度 / 标准值 / 实测值 / gap / 目标水平。
- **学习旅程区**：有序形式列表（课程/项目/辅导，接LD）+ 各项进度/完成状态。
- `[field]`继承的岗位学习方案/地图（只读引用）。

---

## 5. 培养项目（开班制）· 列表 `/develop/projects`

**主操作**：`[btn]创建培养项目`。
**表格列**：`[col]`项目名 / 对象数 / 维度数 / 周期 / 完成度 / 状态`[tag]`(draft/running/done/archived) / 负责人 / 操作。

### 5.1 培养项目向导（①创建 ②选对象 ③选维度 ④选形式 ⑤排期 ⑥跟踪结业）
- **①创建**：`[field]`项目名✅ / `[field]`目标✅ / `[field]`周期✅ / `[field]`负责人。
- **②选对象**：穿梭框（可从人才群组/池导入）。
- **③选维度**：选待补维度（来自盘点差距或岗位学习方案）。
- **④选形式**：每维度配培养形式（课程/项目/辅导，接LD）+ `[field]`引用学习方案模板。
- **⑤排期**：各形式时间安排，生成学习旅程（甘特/列表）。
- **⑥跟踪结业**：`[field]`结业标准(完成率≥X/复测达标)。

### 5.2 培养项目跟踪 `/develop/projects/{id}/tracking`
- KPI 卡：报名数 / 完成率 / 出勤率 / 结业数。
- **成员进度表**：`[col]`成员 / 各形式完成状态 / 总进度 / 结业`[tag]`。
- `[btn]批量写入IDP` `[btn]发起结业复测` → 测评中心。
