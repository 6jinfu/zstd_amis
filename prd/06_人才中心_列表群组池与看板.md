# 人才发展系统 · PRD 06 · 人才中心（人才列表 / 人才群组 / 人才池 / 组织看板 / 胜任看板）

> 沉淀层 · 数据链的总出口
> 依赖：盘点结果、差距、个人发展计划(IDP)、标准、测评、关键岗位 · 本模块不产新数据，只读+按角色分发

---

## 1. 模块目标与规划视角（章森三视角）

人才中心是数据链的沉淀+应用层，按章森"一中心三视角"规划——**HR 的工具 / 员工的平台 / 老板的看板**。五个二级菜单按视角归位：

| 二级菜单 | 规划视角 | 主用户 | 粒度 | 核心价值 |
| --- | --- | --- | --- | --- |
| 人才列表 | HR 工具 | HR | 个人台账 | 全量人才信息底座 |
| 人才群组 | HR 工具 | HR | 群体 | 按条件灵活分群 |
| 人才池 | HR 工具 | HR | 群体（精选） | 关键人才/继任调用库 |
| 组织看板 | 老板的看板 | 老板/高管 | 组织 | 组织故事、分布规律 |
| 胜任看板 | 员工的平台 | 员工/业务领导 | 个人 | 标准 vs 实测胜任度（个人故事） |

> 架构原则：**一套底层数据、多种聚合粒度、按角色做权限**，非多套独立系统。

---

## 2. 菜单一 · 人才列表（HR 工具 · 全量台账）

### 2.1 定位

全量人才的明细台账，是人才中心最细粒度的底座，群组/池/看板都从此派生。

### 2.2 TalentRecord 数据模型

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| employee_id | ref | 员工 |
| name / gender / edu / age | — | People 人员基础信息 |
| tenure | decimal | 司龄 |
| group_id | ref | 所在组（序列×层级，非岗位） |
| position_id | ref | 现岗位 |
| key_position_flag | bool | 是否在关键岗位 |
| latest_t_value | decimal | 最近盘点 T 值 |
| talent_category | enum | HiPo/核心/胜任/问题员工 |
| latest_perf | — | 最近绩效 |

### 2.3 功能

- 多维筛选/排序/导出。
- 列表 → 点击进个人卡片（聚合标准/测评/差距/IDP）。

---

## 3. 菜单二 · 人才群组（HR 工具 · 按条件分群）

### 3.1 定位

按条件（组/绩效/T值/标签/关键岗位等）动态或静态圈出一批人，做批量分析、批量操作的对象集合。

### 3.2 TalentGroup 数据模型

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| group_set_id | string | 主键 |
| name | string | 群组名 |
| filter_type | enum | dynamic 动态(按条件实时)/ static 静态(固定名单) |
| filter_rules | object | 筛选条件（组/绩效/T值区间/标签…） |
| member_refs | array | 成员（静态时固化） |

### 3.3 功能

- 动态群组：条件变化成员自动更新（如"全部 HiPo"）。
- 静态群组：固定名单（如"2026后备干部班"）。
- 群组可作为测评/盘点/培养的批量对象。

---

## 4. 菜单三 · 人才池（HR 工具 · 关键人才/继任库）

### 4.1 定位

盘点沉淀的**精选**人才库——关键岗位人才、HiPo、继任候选，调用导向（选拔/调配/继任）。

### 4.2 TalentPoolEntry 数据模型

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| entry_id | string | 主键 |
| employee_id | ref | 员工 |
| pool_type | enum | 关键岗位池/HiPo池/继任池 |
| target_group_id | ref | 面向的目标组（继任目标） |
| readiness | enum | 准备度（即用/1-2年/3年+） |
| t_value | decimal | 盘点 T 值 |
| review_history | array | 历次盘点轨迹 |

### 4.3 功能

- 按池类型管理；继任池关联目标组与准备度。
- 与关键岗位（岗位中心）联动：看关键岗位的人才覆盖与缺口。

> 群组 vs 池区别：群组是"任意分群工具"，池是"盘点产出的精选关键人才库"。

---

## 5. 菜单四 · 组织看板（老板的看板 · 组织故事）

### 5.1 定位

组织视角——从个人故事跃迁到组织故事，揭示组织规律。"老板最爱听。"

### 5.2 看板内容（组织级聚合）

| 区块 | 数据来源 | 展示 |
| --- | --- | --- |
| 人才分布 | 盘点拟合/交叉 | 年龄×能力、绩效×司龄拟合曲线（含天花板效应） |
| 组织能力基因 | 盘点 A 分析 | 能力优势/短板、枢纽能力 |
| 梯队厚薄 | 序列×层级矩阵 | 各组人才储备分布 |
| 关键岗位储备 | 关键岗位×人才池 | 关键岗位人才覆盖与缺口 |
| 人效视图（增值） | 岗位中心人效数据 | 序列×层级 + 人数/成本/利润 |

### 5.3 权限

- 全组织只读；个体数据脱敏，聚焦规律。

---

## 6. 菜单五 · 胜任看板（员工的平台 · 个人故事）

### 6.1 定位

个人视角，把数据还给本人/直属领导——看某人对其岗位标准的**胜任度**（标准 vs 实测），及差距与发展。

### 6.2 看板内容（个人聚合）

| 区块 | 数据来源 | 展示 |
| --- | --- | --- |
| 岗位标准 | 所在组 Standard | 任职(责-任)+资格(4D)要求 |
| 实测水平 | AssessmentResult | 各维度实测值 |
| 胜任度/差距 | gap_data | 标准 vs 实测，雷达图，达标率 |
| 个人发展计划 | IDP（发展中心） | 当前学习旅程与进度 |
| 发展方向 | IDP 目标 | 下一步要补什么 |

### 6.3 权限

- 员工：仅本人。业务领导：本部门下属。
- 字段级：潜力等敏感维度按配置可隐藏。

## 7. 数据消费关系（本模块不产新数据）

```
People/绩效/盘点 ──> 人才列表（个人台账）
人才列表 ──按条件──> 人才群组（分群）
盘点关键人才 ──> 人才池（精选/继任）
盘点拟合规律 ──> 组织看板（组织故事）
标准+测评+gap_data+IDP ──> 胜任看板（个人故事）
岗位人效数据 ──> 组织看板·人效视图
```

> 若某看板缺数据，根因在上游某步未跑通——可反向验证数据链完整性。

## 9. 验收要点

- [ ] 五个二级菜单：人才列表/人才群组/人才池/组织看板/胜任看板。

- [ ] 人才列表为全量台账底座；群组支持动态/静态分群。

- [ ] 权限按角色行级+字段级控制，归位章森三视角。
