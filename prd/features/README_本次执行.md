## 四、三功能的依赖与数据衔接

```
F01 组织结构分析
  └─ 产出：生效版"岗位族矩阵"(序列×层级的组 Group) + 岗位归类
        │
        ▼
F02 关键岗位诊断（引用 F01 生效版组织结构）
  └─ 产出：各岗位关键系数/象限（诊断依据，不自动定关键）
        │  气泡→抽屉→勾选标记
        ▼
F04 岗位管理
  └─ 关键岗位 = is_key=true 的筛选视图（收口在管理员标记）
  └─ 给关键岗位配：岗位标准(建模表单) / 学习方案(关联培训平台)
```

关键规则：
- **组织结构 = 基准版本型**：入口即可视化矩阵 + 历史版本；唯一"当前生效版"。
- **关键岗位唯一判定 = 管理员标记 `is_key`**；诊断只给依据、不自动进列表；取消标记不丢已配数据。
- **岗位标准表单结构**（任职责-任 + 资格4D）标注"标准库阶段可能调整"，先按 F04 当前版做；能力/动力/潜力选择器数据源=指标库（本次不做指标库，选择器可先留占位/mock）。
