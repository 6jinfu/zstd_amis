## 统一项目制范式（全系统强约束，见 00 §12A）

诊断 / 测评 / 盘点 / 培养 均为**项目制**，共用创建范式：

```
通用四步：① 创建项目 → ② 选择对象 → ③ 选择维度 → ④ 选择工具
盘点专有扩展：⑤ 矩阵组合 → ⑥ 校准
```

所有项目对象继承统一基类（name/goal/scope/dimensions/tools/status/created_by）。

## 数据链（一句话）

定岗位 → 定标准 → 测量 → 盘点（项目） → 发展（IDP/培养项目） → 人才中心沉淀。逻辑通则数据通，数据通则系统活。

## 模块菜单速查

- **岗位中心**：组织结构 / 岗位管理 / 关键岗位诊断 / 指标库 / 模型库
- **评鉴中心**：测评(测评项目/任务/工具/结果) + 盘点(盘点项目，含矩阵组合/校准/历次对比)
- **发展中心**：岗位学习方案 / 岗位地图 / 职级地图 / 个人发展计划 / 培养项目（开班制）
- **人才中心**：人才列表 / 人才群组 / 人才池 / 组织看板 / 胜任看板
